# 第 12 章 OI/ACM 竞赛：ACM 经典题库（总览）

## 17. ACM 经典题库

> 💡 **类比：一本"竞赛真题全解析"**
>
> ACM/ICPC（国际大学生程序设计竞赛）是算法领域最经典的赛事，题目覆盖面广、思维深度高，是检验和提升算法功底的"终极试金石"。本章把竞赛中最常考察的算法整理成一套从易到难的 **1500 道经典题**，按 **19 大分类**组织，每题都附可运行的 Python 参考代码与💡生活化类比思路。
>
> 从枚举模拟、贪心、搜索、数据结构，到图论、动态规划、数论、组合数学、博弈论与计算几何，几乎覆盖了 ACM/ICPC 的全部考点。难度从 ⭐ 到 ⭐⭐⭐ 递进，可作为冲 ICPC 区域赛前的"刷题清单"。
