## 五、通用学习方法

1. **先框架后细节**：先看每章“学习目标”和小结，再进入具体小节。
2. **代码必须手敲**：书中的 Python 示例尽量自己运行一遍，改参数观察输出。
3. **练习先闭卷**：练习题答案默认折叠，先独立完成，再展开对照。
4. **每章做复盘**：用自己的话写出“这个结构/算法解决什么问题、复杂度多少、什么时候会退化”。
5. **按题库查漏**：完成一章后，到对应题库选 3–5 题检验；错题回到章节定位知识点。
