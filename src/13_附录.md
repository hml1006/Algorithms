### 13.2 算法谱系

```
算法
├── 基础算法
│   ├── 枚举 / 模拟
│   ├── 递归 / 迭代
│   ├── 分治
│   ├── 贪心
│   ├── 二分 / 三分
│   └── 前缀和 / 差分
│
├── 排序算法
│   ├── $O(n^2)$: 冒泡 / 选择 / 插入
│   ├── $O(n \log n)$: 归并 / 快排 / 堆排 / Timsort
│   └── $O(n)$: 计数 / 桶 / 基数
│
├── 搜索算法
│   ├── DFS / BFS / IDDFS
│   ├── 回溯 / 分支定界
│   ├── A* / 双向搜索
│   └── 启发式搜索
│
├── 图论算法
│   ├── 遍历: DFS / BFS
│   ├── 最短路: Dijkstra / Bellman-Ford / Floyd / SPFA
│   ├── 最小生成树: Kruskal / Prim
│   ├── 网络流: Dinic / ISAP / 费用流 / 匈牙利 / KM
│   ├── 连通性: Tarjan (SCC / 割点/桥) / Kosaraju
│   ├── 树上: LCA / 树剖 / 树形DP / 树的直径/重心
│   └── 特殊: 拓扑排序 / 欧拉路径 / 2-SAT
│
├── 动态规划
│   ├── 线性 DP / 区间 DP / 背包 DP
│   ├── 树形 DP / 状压 DP / 数位 DP
│   ├── 概率 DP / 博弈 DP / 计数 DP
│   ├── 插头 DP / 轮廓线 DP
│   └── 优化: 斜率优化 / 四边形不等式 / 矩阵优化
│
├── 字符串算法
│   ├── 匹配: KMP / BM / Rabin-Karp / AC 自动机
│   ├── 后缀: 后缀数组 / 后缀自动机 / 后缀树
│   ├── 回文: Manacher / 回文自动机
│   └── 其他: 编辑距离 / Z 函数 / 最小表示法
│
├── 计算几何
│   ├── 凸包 (Graham / Andrew)
│   ├── 旋转卡壳 / 最近点对
│   ├── 半平面交 / 多边形操作
│   └── 最小圆覆盖 / Voronoi 图
│
├── 数论
│   ├── GCD / ExGCD / 欧拉函数 / 中国剩余定理
│   ├── 素数: Miller-Rabin / Pollard-Rho / 线性筛
│   ├── 莫比乌斯反演 / 杜教筛 / Min_25
│   ├── 快速幂 / 矩阵快速幂 / BSGS
│   └── FFT / NTT / 多项式运算
│
└── 高级
    ├── 随机化算法 (Las Vegas / Monte Carlo)
    ├── 近似算法 (PTAS / 在线算法)
    ├── 流算法 (Sketch / Bloom Filter)
    └── 复杂度理论 (P / NP / NP-C / NP-Hard)
```
