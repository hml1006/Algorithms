### 12.1 数论基础与整除

> 涵盖：回文/数位处理、位运算判定 2 的幂、统计二进制 1 的个数、埃氏筛与欧拉线性筛、质因数分解计数尾随零、排序后统计最小绝对差。

#### 12.1.1 例 1：回文数（LeetCode 9）⭐

> **知识点**：数位、反转｜**难度**：⭐（简单）｜**类型**：笔试面试/LeetCode

**思路**

💡 类比"照镜子看前后对称"：回文数在数值上等于"反转后的自己"。为避免反转整个数造成的溢出（虽然 Python 不溢出），更优雅的做法是**只反转后半段数字**，然后与前半段比较：当 `x > rev` 时不断把末尾数字搬进 `rev`，最后比较 `x == rev`（偶数位）或 `x == rev // 10`（奇数位，剔掉中间的对称位）。

```python
def isPalindrome(x: int) -> bool:
    """判断整数是否为回文数"""
    # 负数，或末位为 0 却不为 0，都不可能是回文
    if x < 0 or (x % 10 == 0 and x != 0):
        return False
    rev = 0
    while x > rev:              # 只反转后半段
        rev = rev * 10 + x % 10
        x //= 10
    # 偶数位直接比；奇数位去掉 rev 的中间一位
    return x == rev or x == rev // 10
```

> **复杂度**：O(log x) 时间（位数的一半），O(1) 空间

#### 12.1.2 例 2：2 的幂（LeetCode 231）⭐

> **知识点**：位运算、幂判断｜**难度**：⭐（简单）｜**类型**：笔试面试/LeetCode

**思路**

💡 类比"收摊后只留一盏灯"：2 的幂在二进制中**恰好只有一个 1**。利用位运算技巧 `n & (n - 1)` 可以"消掉最低位的 1"——若结果是 0，说明原本只有一个 1，即 2 的幂。注意还需保证 `n > 0`，并先排除非正数。

```python
def isPowerOfTwo(n: int) -> bool:
    """判断 n 是否为 2 的整数次幂"""
    return n > 0 and (n & (n - 1)) == 0   # n>0 且二进制中仅一个 1
```

> **复杂度**：O(1) 时间，O(1) 空间

#### 12.1.3 例 3：位 1 的个数（LeetCode 191）⭐

> **知识点**：位运算、统计｜**难度**：⭐（简单）｜**类型**：笔试面试/LeetCode

**思路**

💡 类比"一个指头一个指头掰下来"：朴素写法是逐位 `n & 1` 再右移。更快的是利用 `n & (n - 1)` **每次直接消掉最低位的 1**，这样循环次数等于 1 的个数而非位数，对稀疏的二进制尤其划算。

```python
def hammingWeight(n: int) -> int:
    """统计无符号整数的二进制里 1 的个数"""
    cnt = 0
    while n:
        n &= n - 1      # 每次去掉最低位的那个 1
        cnt += 1
    return cnt
```

> **复杂度**：O(k) 时间（k 为 1 的个数），O(1) 空间

#### 12.1.4 例 4：计数质数（LeetCode 204）⭐

> **知识点**：质数筛（埃氏筛 / 欧拉线性筛）｜**难度**：⭐（简单）｜**类型**：笔试面试/LeetCode

**思路**

💡 类比"挨家挨户贴告示"：要数出小于 n 的质数，暴力逐个判断是 O(n√n)。欧拉线性筛思路是——**每个合数只被它的最小质因子筛掉且只筛一次**：遍历 i，若 `is_prime[i]` 成立则入质数表；再用已有质数 p 标记 `i*p` 为合数，一旦 `i % p == 0` 就 break（保证最小质因子唯一），整体达到 O(n)。

```python
def countPrimes(n: int) -> int:
    """统计小于 n 的质数个数（欧拉线性筛）"""
    if n < 3:
        return 0
    is_prime = [True] * n
    is_prime[0] = is_prime[1] = False
    primes = []     # 质数表
    cnt = 0
    for i in range(2, n):
        if is_prime[i]:
            primes.append(i)
            cnt += 1                # i 是质数
        for p in primes:            # 用最小质因子筛合数
            if i * p >= n:
                break
            is_prime[i * p] = False
            if i % p == 0:          # p 已是 i 的最小质因子，避免重复筛
                break
    return cnt
```

> **复杂度**：O(n) 时间（线性），O(n) 空间

#### 12.1.5 例 5：阶乘后的零（LeetCode 172）⭐

> **知识点**：质因数分解、计数｜**难度**：⭐（简单）｜**类型**：笔试面试/LeetCode

**思路**

💡 类比"凑出 10 的搭子"：尾随的 0 由因子 `2×5` 贡献，而 n! 里因子 2 永远够用，所以 0 的个数 = **因子 5 的个数**。等价问题：统计 `1..n` 中 5 的倍数、25 的倍数、125 的倍数……的个数之和，即不断 `n //= 5` 累加。

```python
def trailingZeroes(n: int) -> int:
    """求 n! 末尾连续 0 的个数"""
    cnt = 0
    while n:
        n //= 5             # 统计因子 5 的总个数
        cnt += n
    return cnt
```

> **复杂度**：O(log n) 时间，O(1) 空间

#### 12.1.6 例 6：最小绝对差（LeetCode 1200）⭐

> **知识点**：排序、相邻统计｜**难度**：⭐（简单）｜**类型**：笔试面试/LeetCode

**思路**

💡 类比"排好队找最近的两个人"：排序后，最小绝对差一定出现在相邻元素之间。先排一次序求出全局最小差，再扫一遍把所有"差等于该最小值"的相邻对收集起来即可。

```python
def minimumAbsDifference(arr):
    """找出差值最小的相邻元素对（升序排列若多个）"""
    arr.sort()
    n = len(arr)
    best = min(arr[i + 1] - arr[i] for i in range(n - 1))  # 一次遍历求最小差
    return [[arr[i], arr[i + 1]] for i in range(n - 1)
            if arr[i + 1] - arr[i] == best]
```

> **复杂度**：O(n log n) 时间（排序），O(n) 空间（结果）

#### 12.2.1 例 7：Pow(x, n)（LeetCode 50）⭐⭐

> **知识点**：快速幂｜**难度**：⭐⭐（中等）｜**类型**：笔试面试/LeetCode

**思路**

💡 类比"折半翻倍的大棒"：直接连乘是 O(n)，但利用 `x^8 = (x^4)^2`，每一步把指数减半、底数自乘，配合二进制位判断就能把指数拆成二进制逐位累乘，达到 O(log n)。负指数先取倒数成正指数再快速幂。

```python
def myPow(x: float, n: int) -> float:
    """计算 x 的 n 次幂（快速幂）"""
    if n < 0:
        x, n = 1.0 / x, -n
    res = 1.0
    while n:
        if n & 1:           # 该二进制位为 1，累乘当前底数
            res *= x
        x *= x              # 底数自乘，位权翻倍
        n >>= 1
    return res
```

> **复杂度**：O(log n) 时间，O(1) 空间

#### 12.2.2 例 8：快速幂与模逆元（OI）⭐⭐

> **知识点**：快速幂、扩展欧几里得（ExGCD）、费马小定理、GCD｜**难度**：⭐⭐（中等）｜**类型**：竞赛/OI

**思路**

💡 类比"求倒数在模世界的化身"：`a` 在模 `p` 下的逆元 `a^{-1}` 满足 `a·a^{-1} ≡ 1 (mod p)`。两条路：① **扩展欧几里得**——解线性方程 `a·x + p·y = gcd(a,p)`，当互素时 `x` 即逆元；② **费马小定理**——若 `p` 是质数，`a^{p-2}` 就是逆元，配合快速幂计算。这里把逆元、ExGCD、快速幂三个模板一起给出（模数较大时我们统一用取模版本）。

```python
MOD = 10**9 + 7

def exgcd(a: int, b: int):
    """扩展欧几里得：返回 (g, x, y) 使 a*x + b*y = g = gcd(a,b)"""
    if b == 0:
        return a, 1, 0
    g, x, y = exgcd(b, a % b)
    return g, y, x - (a // b) * y

def qpow(a: int, b: int, mod: int = MOD) -> int:
    """快速幂：求 a^b mod mod"""
    res = 1
    while b:
        if b & 1:
            res = res * a % mod
        a = a * a % mod
        b >>= 1
    return res

def inv_exgcd(a: int, mod: int) -> int:
    """扩展欧几里得求逆元：需 gcd(a, mod)=1，返回 -1 表示不存在"""
    g, x, _ = exgcd(a, mod)
    return x % mod if g == 1 else -1

def inv_fermat(a: int, p: int) -> int:
    """费马小定理求逆元：p 必须为质数，a^{p-2} ≡ a^{-1} (mod p)"""
    return qpow(a % p, p - 2, p)
```

> **复杂度**：ExGCD 与快速幂均 O(log p) 时间，O(1)（或递归栈深度）空间

#### 12.2.3 例 9：超级次方（LeetCode 372）⭐⭐

> **知识点**：快速幂、欧拉函数/欧拉降幂｜**难度**：⭐⭐（中等）｜**类型**：笔试面试/LeetCode

**思路**

💡 类比"逐位喂指数"：指数以数组 `b = [b0,b1,...]` 按十进制给出。核心公式：`(a^{(前若干位)} )^{10} · a^{当前位}`，从高位到低位依次作用。我们已有的模固定为 `1337`。更普适的数论写法是**欧拉降幂**：`a^b mod m` 中指数可取 `b mod φ(m)+φ(m)`，这里 φ(1337)=φ(7·191)=6·190=1140，可保证大指数下也能简化——思路题解采用"逐位快速幂"，并顺带讲解欧拉函数在降幂中的作用。

```python
MOD = 1337

def _pow(a: int, b: int) -> int:
    """快速幂（mod=1337）"""
    res = 1
    a %= MOD
    while b:
        if b & 1:
            res = res * a % MOD
        a = a * a % MOD
        b >>= 1
    return res

def superPow(a: int, b) -> int:
    """计算 a^b mod 1337，b 以十进制数组给出"""
    a %= MOD
    res = 1
    for d in b:
        # (前序结果的 10 次方) × a^当前位，等价于从高位逐位构造指数
        res = _pow(res, 10) * _pow(a, d) % MOD
    return res
```

> **复杂度**：O(∑len(b) · log(数字大小)) 时间，O(1) 空间

#### 12.2.4 例 10：中国剩余定理 CRT（OI）⭐⭐⭐

> **知识点**：同余、扩展欧几里得、中国剩余定理｜**难度**：⭐⭐⭐（困难）｜**类型**：竞赛/OI

**思路**

💡 类比"攒零件拼整数"：解同余式组 `x ≡ a_i (mod m_i)`（m 两两互素）。设 `M = ∏ m_i`、`M_i = M/m_i`，则每项贡献 `a_i · t_i · M_i`，其中 `t_i` 是 `M_i` 关于 `m_i` 的逆元（满足 `t_i·M_i ≡ 1 (mod m_i)`），累加后对 M 取模即得最小的非负解。逆元用扩展欧几里得求解。

```python
def exgcd(a: int, b: int):
    if b == 0:
        return a, 1, 0
    g, x, y = exgcd(b, a % b)
    return g, y, x - (a // b) * y

def crt(a, m):
    """CRT 解同余式组 x ≡ a[i] (mod m[i])，要求 m 两两互素"""
    M = 1
    for mi in m:
        M *= mi                        # 总模数 M
    ans = 0
    for ai, mi in zip(a, m):
        Mi = M // mi
        _, ti, _ = exgcd(Mi, mi)       # Mi 关于 mi 的逆元
        ans = (ans + ai * ti * Mi) % M # 累加每一项的贡献
    return ans
```

> **复杂度**：O(n log M) 时间（n 个方程，每个一次 ExGCD），O(1) 空间

#### 12.2.5 例 11：莫比乌斯反演（OI）⭐⭐⭐

> **知识点**：莫比乌斯函数、线性筛、数论分块/反演与容斥｜**难度**：⭐⭐⭐（困难）｜**类型**：竞赛/OI

**思路**

💡 类比"容斥的计时器"：莫比乌斯函数 μ 定义在正整数上，含平方因子的数 μ=0，质数 μ=-1，质数乘积偶数个为 1、奇数个为 -1。它最常见的递推——`[gcd=1]=Σ_{d|gcd} μ(d)`——把"统计互素对数"转化为枚举公约数 `d`：`Σ μ(d)·⌊n/d⌋²`。可以用线性筛在 O(n) 内求出 μ，再 O(n) 累加回答。

```python
def mobius(n: int):
    """线性筛预处理 [0..n] 的莫比乌斯函数"""
    mu = [0] * (n + 1)
    mu[1] = 1
    primes = []
    is_comp = [False] * (n + 1)
    for i in range(2, n + 1):
        if not is_comp[i]:
            primes.append(i)
            mu[i] = -1                 # 质数 μ=-1
        for p in primes:               # 用最小质因子筛合数
            if i * p > n:
                break
            is_comp[i * p] = True
            if i % p == 0:
                mu[i * p] = 0          # 含平方因子 → 0
                break
            mu[i * p] = -mu[i]         # 新增一个不同质因子，符号取反
    return mu

def coprime_pairs(n: int) -> int:
    """[1..n]×[1..n] 中 gcd(x,y)=1 的有序对个数（莫比乌斯反演）"""
    mu = mobius(n)
    return sum(mu[d] * (n // d) ** 2 for d in range(1, n + 1))
```

> **复杂度**：O(n) 预处理时间，O(n) 空间（每对数回答可再配合整除分块降到 O(√n)）

#### 12.3.1 例 12：卡特兰数与组合计数（OI）⭐⭐

> **知识点**：卡特兰数、组合数取模、二项式/逆元｜**难度**：⭐⭐（中等）｜**类型**：竞赛/OI

**思路**

💡 类比"括号配对与出栈入栈"：卡特兰数 `C_n = C(2n,n)/(n+1)` 刻画了许多计数问题——n 对括号的合法序列数、n 个元素不同的出栈序列数、n×n 网格不越过对角线的路径数等。要正确取模，需要组合数去除法的逆元（费马小定理），下面给出"小 k → 阶乘式"的组合数模板再套闭式。

```python
MOD = 10**9 + 7

def qpow(a: int, b: int) -> int:
    res = 1
    while b:
        if b & 1:
            res = res * a % MOD
        a = a * a % MOD
        b >>= 1
    return res

def comb(n: int, k: int) -> int:
    """组合数 C(n,k) mod MOD，用逆元代替除法（k 较小的情况）"""
    if k < 0 or k > n:
        return 0
    num = den = 1
    for i in range(k):
        num = num * (n - i) % MOD          # 分子 n·(n-1)…(n-k+1)
        den = den * (i + 1) % MOD          # 分母 k!
    return num * qpow(den, MOD - 2) % MOD  # 分母逆元（费马小定理）

def catalan(n: int) -> int:
    """第 n 个卡特兰数：C_n = C(2n,n)/(n+1)"""
    return comb(2 * n, n) * qpow(n + 1, MOD - 2) % MOD
```

> **复杂度**：O(n log MOD) 时间（求单个组合数及一次逆元），O(1) 空间

#### 12.3.2 例 13：错排与容斥（OI）⭐⭐

> **知识点**：错排递推、容斥原理｜**难度**：⭐⭐（中等）｜**类型**：竞赛/OI

**思路**

💡 类比"no one 坐在原位"：n 个元素排列后没有任何一个在原来位置，就是错排。经典递推 `D_n = (n-1)·(D_{n-1} + D_{n-2})`，边界 `D_1=0, D_2=1`。其来源与**容斥**直接相关：总排列 n! 减去至少有 1 个在位的、加上至少有 2 个在位的……即 `D_n = Σ (-1)^k C(n,k)(n-k)!`。递推实现 O(n)，也便于理解。

```python
def derange(n: int) -> int:
    """n 个元素的错位排列数 D_n（D0=1, D1=0, D2=1）"""
    if n == 0:
        return 1
    if n == 1:
        return 0
    d_prev2, d_prev1 = 1, 0          # D[0]=1, D[1]=0
    for i in range(2, n + 1):
        d_cur = (i - 1) * (d_prev1 + d_prev2)   # D[i]=(i-1)(D[i-1]+D[i-2])
        d_prev2, d_prev1 = d_prev1, d_cur
    return d_prev1
```

> **复杂度**：O(n) 时间，O(1) 空间

#### 12.3.3 例 14：概率与期望（OI）⭐⭐

> **知识点**：概率、期望线性性、几何分布｜**难度**：⭐⭐（中等）｜**类型**：竞赛/OI

**思路**

💡 类比"一笔一笔算账不吃亏"：期望最大的杀器是**线性性**——`E[X+Y]=E[X]+E[Y]`，即使 X、Y 相关也成立。因此 n 次独立抛硬币的正面次数期望 = n 个指示变量期望之和 = n/2；而"掷均匀骰子直到首次掷出 6"服从几何分布，期望 = 1/p = 6。给出两个直观例子展示线性性与几何分布的推导写法。

```python
def expected_heads(n: int) -> float:
    """n 次抛硬币正面次数的期望，用线性性 E[X]=ΣE[Xi]"""
    return n * 0.5       # 每枚硬币贡献 E[Xi] = 0.5

def expected_rolls_to_six() -> float:
    """首次掷出 6 所需次数的期望：几何分布 E = 1/p"""
    p = 1 / 6
    # 推导: E = Σ_{k>=1} k·(1-p)^(k-1)·p = 1/p
    return 1 / p         # = 6.0
```

> **复杂度**：O(1) 时间，O(1) 空间（实际竞赛中常需配合概率 DP 或组合数递推）

### 12.4 计算几何

#### 12.4.1 例 15：直线上最多的点数（LeetCode 149）⭐⭐⭐

> **知识点**：计算几何、哈希表、概率（随机采样可选）｜**难度**：⭐⭐⭐（困难）｜**类型**：笔试面试/LeetCode

**思路**

💡 类比"找最拥挤的一条排"：固定一个点 i，其它点与之构成的斜率（用"dx、dy 各自除以 gcd 后取标准方向"表示，**避免浮点误差**）相同的点都位于过 i 的同一直线上。枚举每个 i，用哈希表统计各斜率出现次数，答案取最大。重复点（dx=dy=0）单独累计。整体 O(n²)。

```python
from math import gcd
from collections import defaultdict

def maxPoints(points) -> int:
    """返回在同一条直线上的最多点数"""
    n = len(points)
    if n < 3:
        return n
    ans = 0
    for i in range(n):
        slopes = defaultdict(int)   # 标准斜率 -> 点数
        same = 1                    # 与 points[i] 重合的点（含自身）
        for j in range(i + 1, n):
            dx = points[j][0] - points[i][0]
            dy = points[j][1] - points[i][1]
            if dx == 0 and dy == 0:     # 重合点
                same += 1
                continue
            g = gcd(dx, dy)             # 化简为最简分数，去浮点误差
            dx //= g
            dy //= g
            # 统一斜率方向：dy 恒非负；dy==0 时令 dx>0
            if dy < 0 or (dy == 0 and dx < 0):
                dx, dy = -dx, -dy
            slopes[(dx, dy)] += 1
        ans = max(ans, same + max(slopes.values(), default=0))
    return ans
```

> **复杂度**：O(n²) 时间，O(n) 空间（单轮斜率哈希表）

#### 12.4.2 例 16：凸包模板（Andrew 扫描 / OI）⭐⭐⭐

> **知识点**：凸包、叉积、极角/单调栈｜**难度**：⭐⭐⭐（困难）｜**类型**：竞赛/OI

**思路**

💡 类比"给点云拉一条橡皮筋"：Andrew 算法先将点按 (x, y) 排序，然后用单调栈分别构造**下凸包**和**上凸包**。转向判定依赖**叉积**：`cross(o,a,b) = (a-o)×(b-o)`，叉积 ≤ 0 说明向右转或共线不需「向外凸」，应弹出栈顶。最后合并上下包即为凸包顶点（首尾去掉重复）。

```python
def cross(o, a, b):
    """向量 oa 与 ob 的叉积 z 分量；>0 逆时针（左转）"""
    return (a[0] - o[0]) * (b[1] - o[1]) - (a[1] - o[1]) * (b[0] - o[0])

def convex_hull(points):
    """Andrew 求凸包（输出逆时针、不含边缘共线中间点可调整）"""
    pts = sorted(points)          # 先按 x 再按 y 排序
    if len(pts) <= 1:
        return pts
    lower = []
    for p in pts:                 # 下凸包
        while len(lower) >= 2 and cross(lower[-2], lower[-1], p) <= 0:
            lower.pop()
        lower.append(p)
    upper = []
    for p in reversed(pts):       # 上凸包
        while len(upper) >= 2 and cross(upper[-2], upper[-1], p) <= 0:
            upper.pop()
        upper.append(p)
    return lower[:-1] + upper[:-1]  # 首尾各重复一次，去掉
```

> **复杂度**：O(n log n) 时间（排序主导），O(n) 空间

#### 12.4.3 例 17：旋转卡壳（凸包直径 / OI）⭐⭐⭐

> **知识点**：旋转卡壳、叉积、最远点对｜**难度**：⭐⭐⭐（困难）｜**类型**：竞赛/OI

**思路**

💡 类比"贴着凸包的滚轮"：凸包上的**最远点对**（直径）可由两个对踵点给出，用旋转卡壳在 O(n) 内双指针滚动求出。对每条边 (i, i+1)，把指针 j 沿凸包推进，只要 `j+1` 处到该边构成的三**面积（叉积）**严格增大就继续推（面积最大处即最远点），从而更新最长距离平方。需按角度单调性限制步数以保证终止。

```python
def rotating_calipers(hull):
    """求凸包直径（最远点对距离的平方）"""
    n = len(hull)
    if n < 2:
        return 0
    def area(i, j, k):                      # 以 i 为基准，|cross(ij,ik)|
        return abs((hull[j][0]-hull[i][0]) * (hull[k][1]-hull[i][1])
                   - (hull[j][1]-hull[i][1]) * (hull[k][0]-hull[i][0]))
    def dist2(a, b):
        return (a[0]-b[0]) ** 2 + (a[1]-b[1]) ** 2
    j = 1
    best = 0
    for i in range(n):
        ni = (i + 1) % n
        steps = 0
        # j 每轮只沿凸包单向前进，总体 O(n)
        while steps < n and area(i, ni, (j + 1) % n) > area(i, ni, j % n):
            j = (j + 1) % n
            steps += 1
        best = max(best, dist2(hull[i], hull[j % n]),
                   dist2(hull[ni], hull[j % n]))
    return best
```

> **复杂度**：O(n) 时间（j 单向至多走一圈），O(1) 空间

#### 12.4.4 例 18：最近点对（分治）与半平面交概念（OI）⭐⭐⭐

> **知识点**：最近点对、分治、几何剪枝；半平面交概念｜**难度**：⭐⭐⭐（困难）｜**类型**：竞赛/OI

**思路**

💡 类比"先分广场再比肩邻"：最近点对用**分治法**：按 x 中轴一分为二，递归求得左右的最小距离 d，再检查跨越中轴、落在 `|x-中轴x| < d` 的带状区间内的点（按 y 排序后，只需与后面至多几个点比较即可剪枝），合并取 min，整体 O(n log n)。**半平面交**则是另一几何主题：把每条线性约束看作取半平面，求这些半平面的公共交集，得到的是一凸多边形（或空/直线），是凸轮、线性规划 USP参考解法；此处给出最近点对关键实现。

```python
import math

def _dist(a, b):
    return math.hypot(a[0] - b[0], a[1] - b[1])

def closest(points):
    """分治法求点集中最近点对距离"""
    pts = sorted(points)                # 按 x 预排序
    n = len(pts)
    def rec(l, r):
        if l >= r:
            return float('inf')
        if r - l == 1:
            return _dist(pts[l], pts[r])
        mid = (l + r) // 2
        mx = pts[mid][0]
        d = min(rec(l, mid), rec(mid + 1, r))   # 左右递归
        strip = [p for p in pts[l:r + 1] if abs(p[0] - mx) < d]
        strip.sort(key=lambda p: p[1])
        for i in range(len(strip)):
            for j in range(i + 1, len(strip)):
                if strip[j][1] - strip[i][1] >= d:
                    break                       # y 差距已超，提前收束
                d = min(d, _dist(strip[i], strip[j]))
        return d
    return rec(0, n - 1)
```

> **复杂度**：O(n log n) 时间（分治 + 剪枝），O(n) 空间
>
> 💡 **半平面交（延伸概念）**：将每条约束 `ax+by+c` 的方向固定，取满足非负侧的半平面；逐条求交可维护一个凸多边形/双端队列。常用来求出可行域与最远交点，是 OI 中更高阶的几何素材。

#### 12.5.1 例 19：三除数（LeetCode 1952）⭐

> **知识点**：质数判定、因数个数｜**难度**：⭐（简单）｜**类型**：笔试面试/LeetCode

**思路**

💡 类比"恰好摊成三份"：一个正整数**恰好只有 3 个正因数**，当且仅当它是某个质数的平方。因为标准分解 `n=p1^a1·p2^a2...`，因数个数为 `Π(ai+1)`；要等于 3，只能形如 `p²`。所以先判断 n 是否为完全平方数，再判断其平方根是否为质数。

```python
import math

def isThree(n: int) -> bool:
    r = math.isqrt(n)
    if r * r != n or r < 2:
        return False
    for i in range(2, math.isqrt(r) + 1):
        if r % i == 0:
            return False
    return True

print(isThree(2), isThree(9), isThree(12))   # False True False
```

> **复杂度**：O(√√n) 时间，O(1) 空间

#### 12.5.2 例 20：素因子计数（约数个数模板，OI）⭐

> **知识点**：质因数分解、唯一分解定理｜**难度**：⭐（简单）｜**类型**：竞赛/OI

**思路**

💡 类比"数盒子里的隔层"：唯一分解 `n = Π pi^ai`，则**正因子个数**=`Π(ai+1)`。做法是试除 `d=2,3,4,...`，凡是整除就除尽并计指数；只需试到 `d*d <= n`，最后若 `n>1` 说明剩下一个质因子，次数为 1。

```python
def divisor_count(n: int) -> int:
    cnt = 1
    d = 2
    while d * d <= n:
        exp = 0
        while n % d == 0:
            n //= d
            exp += 1
        cnt *= (exp + 1)
        d += 1
    if n > 1:
        cnt *= 2
    return cnt

print(divisor_count(12), divisor_count(36))   # 6 9
```

> **复杂度**：O(√n) 时间（最坏），O(1) 空间

#### 12.5.3 例 21：质数排列（LeetCode 1175）⭐⭐

> **知识点**：质数判定、排列、组合取模｜**难度**：⭐⭐（中等）｜**类型**：LeetCode/数论

**思路**

💡 类比"质数坐质数位"：把 1..n 里的质数放到位次为质数的位置、合数放到位次为合数的位置，方案数=`P! × (n-P)!`。其中 P 是 1..n 中质数的个数，对 1e9+7 取模。

```python
MOD = 10 ** 9 + 7

def numPrimeArrangements(n: int) -> int:
    def is_prime(x):
        if x < 2:
            return False
        i = 2
        while i * i <= x:
            if x % i == 0:
                return False
            i += 1
        return True

    prime_cnt = sum(1 for x in range(1, n + 1) if is_prime(x))
    def fac(m):
        r = 1
        for i in range(2, m + 1):
            r = r * i % MOD
        return r
    return fac(prime_cnt) * fac(n - prime_cnt) % MOD

print(numPrimeArrangements(5))   # 12
```

> **复杂度**：O(n√n) 时间，O(1) 空间

#### 12.5.4 例 22：丑数（漂亮数，LeetCode 263）⭐

> **知识点**：整除、质因子、退化处理｜**难度**：⭐（简单）｜**类型**：笔试面试/LeetCode

💡 类比"只会用 2、3、5 三种积木搭"：丑数指**质因数仅含 2、3、5 的正整数**。做法是把 n 反复除尽 2、3、5，若最后剩 1 说明无其他质因子即为丑数。注意负数/0 一定不是丑数。

```python
def isUgly(n: int) -> bool:
    if n <= 0:
        return False
    for p in (2, 3, 5):

            n //= p
    return n == 1

print(isUgly(6), isUgly(8), isUgly(14))   # True True False
```

#### 12.5.5 例 23：可被 K 整除的最小整数（LeetCode 1015）⭐⭐

> **知识点**：取余、同余、抽屉原理｜**难度**：⭐⭐（中等）｜**类型**：LeetCode/数论

**思路**

💡 类比"用取余限制无限增长"：要找最小的全 1 数 `1,11,111,...` 能被 k 整除。直接构建整数会溢出，改用递推 `r = (r*10+1) % k` 只保留余数。若 k 是 2 或 5 的倍数，尾位不可能凑出整除，直接返回 -1；否则由抽屉原理知长度至多到 k 一定出现整除或循环。

```python
def smallestRepunitDivByK(k: int) -> int:
    if k % 2 == 0 or k % 5 == 0:
        return -1
    r = 0
    for length in range(1, k + 1):
        r = (r * 10 + 1) % k
        if r == 0:
            return length
    return -1

print(smallestRepunitDivByK(1), smallestRepunitDivByK(3), smallestRepunitDivByK(11))   # 1 3 2
```

> **复杂度**：O(k) 时间，O(1) 空间

#### 12.5.6 例 24：最大公约数与最小公倍数模板（OI）⭐

> **知识点**：辗转相除法、GCD/LCM｜**难度**：⭐（简单）｜**类型**：竞赛/OI

**思路**

💡 类比"把两份拼图对齐"：`gcd(a,b)` 用**辗转相除** `gcd(b, a%b)` 收敛到 0 时的 a；`lcm(a,b) = a/gcd(a,b)*b`（先除后乘避免溢出）。这是数论题的"地基"，几乎所有题目都先用它约分或保证互质。

```python
def gcd(a, b):
    return a if b == 0 else gcd(b, a % b)

def lcm(a, b):
    return a // gcd(a, b) * b   # 先除后乘防溢出

print(gcd(12, 18), lcm(4, 6))   # 6 12
```

> **复杂度**：O(log min(a,b)) 时间，O(1) 空间（递归栈 O(log)）

#### 12.5.8 例 26：组合数取模 C(n,k) mod p（OI）⭐⭐

> **知识点**：阶乘打表、费马小定理求逆元｜**难度**：⭐⭐（中等）｜**类型**：竞赛/OI

**思路**

💡 类比"先算好钥匙再快速开锁"：要算 `C(n,k) mod p`（p 为质数），预处理 `fac[i]=i!` 与 `inv_fac[i]=(i!)^-1`。逆元用**费马小定理** `inv(x)=pow(x, p-2, p)`；`inv_fac[i-1]=inv_fac[i]*i` 可 O(1) 递推得到全部。答案即 `fac[n]*inv_fac[k]*inv_fac[n-k]`。

```python
MOD = 10 ** 9 + 7

def nCk_mod(n: int, k: int, mod=MOD) -> int:
    if k < 0 or k > n:
        return 0
    k = min(k, n - k)
    fac = [1] * (n + 1)
    for i in range(1, n + 1):
        fac[i] = fac[i - 1] * i % mod
    inv_fac = [1] * (n + 1)
    inv_fac[n] = pow(fac[n], mod - 2, mod)       # 费马小定理：一次求大逆元
    for i in range(n, 0, -1):
        inv_fac[i - 1] = inv_fac[i] * i % mod    # 倒推其余逆元
    return fac[n] * inv_fac[k] % mod * inv_fac[n - k] % mod

print(nCk_mod(5, 2))   # 10
```

> **复杂度**：O(n) 预处理，O(1) 单次查询；O(n) 空间

#### 12.6.1 例 27：杨辉三角（LeetCode 118）⭐

**思路**

💡 类比"上一层叠积木"：杨辉三角第 i 行第 j 个数正好是 `C(i,j)`，满足 `C(i,j)=C(i-1,j-1)+C(i-1,j)`，两端恒为 1。

```python
def generate(numRows):
    tri = []
    for i in range(numRows):
        row = [1] * (i + 1)
        for j in range(1, i):
            row[j] = tri[i - 1][j - 1] + tri[i - 1][j]
        tri.append(row)
    return tri

print(generate(5))
```

#### 12.6.2 例 28：第 k 个排列（LeetCode 60）⭐⭐⭐

> **知识点**：阶乘计数、按位构造｜**难度**：⭐⭐⭐（困难）｜**类型**：LeetCode/组合

**思路**

💡 类比"翻目录按组跳页"：`1..n` 的全排列按字典序排好后，第 k 个可通过**阶乘定位**构造——高位确定后，剩下数的排列数为 `(剩余个数)!`。每次用 `idx = k // fac[i-1]` 决定当前位取第几个候选，`k %= fac[i-1]` 更新剩余偏移。

```python
def getPermutation(n: int, k: int) -> str:
    fac = [1] * (n + 1)
    for i in range(1, n + 1):
        fac[i] = fac[i - 1] * i
    nums = list(range(1, n + 1))
    k -= 1
    res = []
    for i in range(n, 0, -1):
        idx = k // fac[i - 1]
        k %= fac[i - 1]
        res.append(str(nums.pop(idx)))
    return ''.join(res)

print(getPermutation(3, 3))   # 213
```

> **复杂度**：O(n²) 时间（pop 为 O(n)），O(n) 空间

#### 12.6.3 例 29：阶乘函数后 K 个零（LeetCode 793）⭐⭐⭐

> **知识点**：因子 5 计数、二分答案｜**难度**：⭐⭐⭐（困难）｜**类型**：LeetCode/数论

**思路**

💡 类比"倒着找断点"：`x!` 尾零个数 `f(x)` 随 x 单调不减但会跳跃（例如 24! 有 4 个零、25! 跳到 6 个零，永远没有 5 个）。用**二分**找最小的 x 使 `f(x) >= K`，若该处恰好等于 K，则 x 到 x+4 五个数同值，答案是 5；否则答案 0。

```python
def _tz(n):
    c = 0
    while n >= 5:
        n //= 5
        c += n
    return c

def preimageSizeFZF(k: int) -> int:
    def find(x):
        lo, hi = 0, 10 ** 10
        while lo < hi:
            mid = (lo + hi) // 2
            if _tz(mid) < x:
                lo = mid + 1
            else:
                hi = mid
        return lo
    a = find(k)
    return 5 if _tz(a) == k else 0

print(preimageSizeFZF(0), preimageSizeFZF(5))   # 5 0
```

> **复杂度**：O(log² n) 时间，O(1) 空间

#### 12.6.4 例 30：快乐数（LeetCode 202）⭐

```python
            return v % 10 + 1

    cnt[rand10()] += 1
```

#### 12.7.5 例 37：打乱数组（Fisher-Yates 洗牌，LeetCode 384）⭐⭐

> **知识点**：洗牌算法、均匀随机｜**难度**：⭐⭐（中等）｜**类型**：笔试面试/算法设计

**思路**

💡 类比"从后往前抽牌"：保证每种排列等概率的核心是**每个位置只与"向后"的元素交换**。从 i 从大到小，`j = randint(0, i)` 与 `arr[i]` 交换，概率严格均匀。

```python
import random

class Solution:
    def __init__(self, nums):
        self.original = list(nums)
        self.arr = list(nums)

    def reset(self):
        self.arr = list(self.original)
        return self.arr

    def shuffle(self):
        a = list(self.arr)
        for i in range(len(a) - 1, 0, -1):
            j = random.randint(0, i)
            a[i], a[j] = a[j], a[i]
        return a

s = Solution([1, 2, 3, 4])
print(s.shuffle())
print(s.reset())
```

> **复杂度**：O(n) 时间（洗牌 / reset），O(n) 空间

#### 12.8.1 例 38：点到直线的距离（OI）⭐

> **知识点**：向量叉积、几何公式｜**难度**：⭐（简单）｜**类型**：竞赛/OI

**思路**

💡 类比"叉积面积除以底"：点 P 到直线 AB 的距离，等于以 AB、AP 为边的平行四边形面积（`|AB × AP|`）除以底 `|AB|`。叉积 `vx*wy - vy*wx` 即二维向量叉积的 z 分量。

```python
import math

def point_to_line(px, py, ax, ay, bx, by):
    vx, vy = bx - ax, by - ay
    wx, wy = px - ax, py - ay
    if vx == 0 and vy == 0:
        return math.hypot(wx, wy)
    cross = abs(vx * wy - vy * wx)
    return cross / math.hypot(vx, vy)

print(round(point_to_line(1, 1, 0, 0, 4, 0), 4))   # 1.0
```

> **复杂度**：O(1) 时间，O(1) 空间

#### 12.8.3 例 40：两条直线的交点（OI）⭐⭐

> **知识点**：直线方程、行列式判并行｜**难度**：⭐⭐（中等）｜**类型**：竞赛/OI

**思路**

💡 类比"两条路交叉唯一定点"：用 Cramer 法则解二元一次方程组。分母 `denom = (x1-x2)(y3-y4) - (y1-y2)(x3-x4)`，若为 0 说明平行/共线返回 None，否则代回求得交点坐标。

```python
def line_intersection(ax, ay, bx, by, cx, cy, dx, dy):
    x1, y1, x2, y2 = ax, ay, bx, by
    x3, y3, x4, y4 = cx, cy, dx, dy
    denom = (x1 - x2) * (y3 - y4) - (y1 - y2) * (x3 - x4)
    if denom == 0:
        return None
    px = ((x1 * y2 - y1 * x2) * (x3 - x4) - (x1 - x2) * (x3 * y4 - y3 * x4)) / denom
    py = ((x1 * y2 - y1 * x2) * (y3 - y4) - (y1 - y2) * (x3 * y4 - y3 * x4)) / denom
    return (px, py)

print(line_intersection(0, 0, 1, 1, 0, 1, 1, 0))   # (0.5, 0.5)
```

> **复杂度**：O(1) 时间，O(1) 空间

```python
def fractionToDecimal(numerator: int, denominator: int) -> str:
    sign = '-' if numerator * denominator < 0 else ''
    num, den = abs(numerator), abs(denominator)
    int_part = num // den
    remain = num % den
    if remain == 0:
        return sign + str(int_part)
    res = [sign + str(int_part) + '.']
    mp = {}
    while remain and remain not in mp:
        mp[remain] = len(res)
        remain *= 10
        res.append(str(remain // den))
        remain %= den
    if remain:
        idx = mp[remain]
        res.insert(idx, '(')
        res.append(')')
    return ''.join(res)
```

### 12.10 数论进阶：欧拉函数与费马小定理

> 涵盖：欧拉函数 φ(n) 模板、与 n 互质的整数之和、欧拉函数区间前缀和、用欧拉定理对超大指数降幂取模。

#### 12.10.1 例 44：欧拉函数 φ(n) 模板（OI）⭐⭐

> **知识点**：质因数分解、欧拉函数｜**难度**：⭐⭐（中等）｜**类型**：OI/数论模板

**思路**

💡 类比"逐个剥离质因数"：φ(n) 表示 **1 到 n 中与 n 互质的数的个数**，公式为 `φ(n) = n·Π(1 - 1/p)`，`p` 遍历 n 的**不同**质因子。用试除法从小到大除出每个质因子，每遇到一个新质因子 `p` 就做 `res -= res // p`，最后的残余 `n > 1` 说明它还是一个质因子。

```python
def euler_phi(n):
    """计算欧拉函数 φ(n)：1..n 中与 n 互质的整数个数"""
    res = n
    p = 2
    while p * p <= n:
        if n % p == 0:
            res -= res // p           # 剔除含因子 p 的数
            while n % p == 0:         # 剥离该质因子的所有幂次
                n //= p
        p += 1
    if n > 1:                          # 残余的大于1的因数是质数
        res -= res // n
    return res

print(euler_phi(1))    # 1
print(euler_phi(10))   # 4  （1,3,7,9 与 10 互质）
print(euler_phi(97))   # 96 （97 是质数）
```

> **复杂度**：O(√n) 时间，O(1) 空间

#### 12.10.2 例 45：与 n 互质的整数之和（OI）⭐⭐

> **知识点**：欧拉函数、配对求和｜**难度**：⭐⭐（中等）｜**类型**：OI/数论

**思路**

💡 类比"首尾相加凑对称"：把 1..n 中所有与 n 互质的数首尾配对求和。若 `x` 与 `n` 互质，则 `n - x` 也与 `n` 互质，二者配对和为 `n`，共有 `φ(n)/2` 对，故总和为 `n·φ(n)/2`（n=1 时单独处理）。

```python
def euler_phi(n):
    res = n
    p = 2
    while p * p <= n:
        if n % p == 0:
            res -= res // p
            while n % p == 0:
                n //= p
        p += 1
    if n > 1:
        res -= res // n
    return res

def sum_coprime(n):
    if n == 1:
        return 1
    return n * euler_phi(n) // 2

print(sum_coprime(10))  # 1+3+7+9 = 20 = 10*4//2
print(sum_coprime(6))   # 1+5 = 6
```

> **复杂度**：O(√n) 时间，O(1) 空间

#### 12.10.3 例 46：欧拉函数前缀和计数（OI）⭐⭐⭐

> **知识点**：线性筛/埃氏筛、欧拉函数｜**难度**：⭐⭐⭐（困难）｜**类型**：OI/数论

**思路**

💡 类比"筛子把质数标出来，同时把 φ 一步步摊开"：一次循环同时计算 **1..n 每个数的 φ**。`phi[i] == i` 说明 i 尚未被更小的素因子处理过即 i 为质数，于是把 `i` 作为质因子贡献给它的所有倍数 `j`（`phi[j] -= phi[j] // i`）。最后累加即得前缀和。

```python
def phi_prefix_sum(n):
    """返回 sum_{i=1}^{n} phi(i)"""
    phi = list(range(n + 1))           # phi[i] 初值 i
    for i in range(2, n + 1):
        if phi[i] == i:                # i 是质数
            for j in range(i, n + 1, i):
                phi[j] -= phi[j] // i
    return sum(phi[1:])

print(phi_prefix_sum(10))   # 1+1+2+2+4+2+6+4+6+4 = 32
print(phi_prefix_sum(6))    # 1+1+2+2+4+2 = 12
```

> **复杂度**：O(n·log log n)（调和级数）时间，O(n) 空间

#### 12.10.4 例 47：超大指数取模 A^(B^C) mod M（欧拉降幂，OI）⭐⭐⭐

> **知识点**：欧拉定理、快速幂、欧拉函数｜**难度**：⭐⭐⭐（困难）｜**类型**：OI/数论进阶

**思路**

💡 类比"指数站在两层楼上，我们先把脚底的指数对 φ(M) 取个模"：欧拉定理说当 `gcd(A,M)=1` 时 `A^φ(M) ≡ 1 (mod M)`，因此指数可以**先对 φ(M) 取模再算**。于是 `A^(B^C) mod M = (A^( (B^C) mod φ(M) ) ) mod M`，其中内层指数再用快速幂计算。

```python
def euler_phi(n):
    res = n
    p = 2
    while p * p <= n:
        if n % p == 0:
            res -= res // p
            while n % p == 0:
                n //= p
        p += 1
    if n > 1:
        res -= res // n
    return res

def pow_mod(a, b, m):
    a %= m
    res = 1
    while b:
        if b & 1:
            res = res * a % m
        a = a * a % m
        b >>= 1
    return res

def super_pow(A, B, C, M):
    if M == 1:
        return 0
    phi = euler_phi(M)                     # 对指数降幂的模
    exp = pow_mod(B, C, phi)               # B^C mod phi(M)
    return pow_mod(A, exp, M)

print(super_pow(2, 3, 2, 5))   # 2^(3^2)=2^9=512, 512%5=2
print(super_pow(2, 10, 2, 7))  # 2^100 mod 7: 2^3=8≡1, 100%3=1 -> 2
print(super_pow(3, 4, 1, 7))   # 3^(4^1)=3^4=81, 81%7=4
```

> **复杂度**：O(log B + log C + √M) 时间，O(1) 空间

> **知识点**：斯特林数、动态规划｜**难度**：⭐⭐（中等）｜**类型**：OI/组合计数

**思路**

💡 类比"新来一个人决定自己开新盒还是进已有盒"：第二类斯特林数 `S(n,m)` 表示**把 n 个不同的小球放进 m 个相同的非空盒子**的方案数。递推 `S(n,m)=S(n-1,m-1)+m·S(n-1,m)`：第 n 个球要么独自开一个新盒（`S(n-1,m-1)`），要么放入 m 个已有盒之一（`S(n-1,m)` 有 m 种选择）。

```python
def stirling2(n, m):
    """第二类斯特林数 S(n,m)"""
    dp = [[0] * (m + 1) for _ in range(n + 1)]
    dp[0][0] = 1
    for i in range(1, n + 1):
        for j in range(1, min(i, m) + 1):
            dp[i][j] = dp[i - 1][j - 1] + j * dp[i - 1][j]
    return dp[n][m]

print(stirling2(5, 3))   # 25
print(stirling2(4, 2))   # 7
```

> **复杂度**：O(n·m) 时间，O(n·m) 空间

#### 12.11.3 例 50：组合数取模 C(n,k) mod p（Lucas 定理，OI）⭐⭐⭐

> **知识点**：Lucas 定理、费马小定理求逆元、快速幂｜**难度**：⭐⭐⭐（困难）｜**类型**：OI/组合计数进阶

**思路**

💡 类比"把大数切成长度 p 的数位，再用小组合数拼回"：当 `p` 为质数且 `n` 很大时，Lucas 定理说 `C(n,k)≡C(n//p,k//p)·C(n%p,k%p) (mod p)`。递归地把 `n,k` 每轮除以 p，只需预计算 `[0,p-1]` 的阶乘与逆元阶乘，即可用**费马小定理**（`inv(x)=x^(p-2) mod p`）求逆元算了。

```python
def comb_mod(n, k, p):
    """C(n,k) mod p，p 为小质数"""
    # 预计算阶乘与逆元阶乘
    fac = [1] * p
    for i in range(1, p):
        fac[i] = fac[i - 1] * i % p
    ifac = [1] * p
    ifac[p - 1] = pow(fac[p - 1], p - 2, p)      # 费马小定理
    for i in range(p - 2, -1, -1):
        ifac[i] = ifac[i + 1] * (i + 1) % p

    res = 1
    while n or k:
        ni, ki = n % p, k % p
        if ki > ni:
            return 0
        res = res * fac[ni] % p
        res = res * ifac[ki] % p
        res = res * ifac[ni - ki] % p
        n //= p
        k //= p
    return res

print(comb_mod(5, 2, 7))    # C(5,2)=10 -> 10%7=3
print(comb_mod(100, 50, 101))  # 101 质数, C(100,50) mod 101
print(comb_mod(6, 3, 5))    # C(6,3)=20 -> 20%5=0
```

> **复杂度**：O(p + log_p n) 时间，O(p) 空间

#### 12.11.4 例 51：第一类斯特林数·环排列（OI）⭐⭐⭐

> **知识点**：斯特林数、圆排列、动态规划｜**难度**：⭐⭐⭐（困难）｜**类型**：OI/组合计数进阶

**思路**

💡 类比"新元素插入已有环的任意空隙，或自己新开一个环"：无符号第一类斯特林数 `s(n,m)` 表示**把 n 个不同元素排成 m 个非空循环排列（圆环）**的方案数。递推 `s(n,m)=s(n-1,m-1)+(n-1)·s(n-1,m)`：第 n 个元素要么独自开新环，要么插到前一状态下 `n-1` 个元素的任一空隙中。

```python
def stirling1(n, m):
    """无符号第一类斯特林数 s(n,m)"""
    dp = [[0] * (m + 1) for _ in range(n + 1)]
    dp[0][0] = 1
    for i in range(1, n + 1):
        for j in range(1, m + 1):
            dp[i][j] = dp[i - 1][j - 1] + (i - 1) * dp[i - 1][j]
    return dp[n][m]

print(stirling1(4, 2))   # 11
print(stirling1(3, 2))   # 3  （{1,2,3} 分成 1 环+2 环）
```

> **复杂度**：O(n·m) 时间，O(n·m) 空间

### 12.12 模运算与数论进阶应用

> 涵盖：十进制大数对模取余、指数幂的最后 K 位、模数运算表达式的求值。

#### 12.12.1 例 52：十进制大数取模（OI）⭐

> **知识点**：模运算性质｜**难度**：⭐（简单）｜**类型**：OI/模运算

**思路**

💡 类比"逐位一位位『滚雪球』地取余"：利用 `(a·10 + b) mod m = ( (a mod m)·10 + b ) mod m`，从最高位开始不断 `r = (r*10 + digit) % m`，无需把大数转为整型即不溢出。这是处理超长字符串大数的标准技巧。

```python
def big_mod(s, m):
    """字符串表示的大数 s 对 m 取模"""
    r = 0
    for ch in s:
        r = (r * 10 + int(ch)) % m
    return r

print(big_mod("12345678901234567890", 97))
print(big_mod("99999999999999999999", 7))   # 10^20-1 mod 7
```

#### 12.12.2 例 53：指数幂的末 K 位（OI）⭐⭐

> **知识点**：快速幂、模运算｜**难度**：⭐⭐（中等）｜**类型**：OI/模运算应用

**思路**

💡 类比"算到一半就掐掉前几位"：求 `a^b` 的后 K 位只需在模 `10^K` 下做快速幂。`(a·a) mod 10^K` 天然保留低 K 位，最终用 `zfill` 补足前导零即可（注意 0 次幂结果为 1）。

```python
def last_k_digits(a, b, k):
    """a^b 的末 K 位数字（b 可为超大）"""
    m = 10 ** k
    base, res = a % m, 1
    while b:
        if b & 1:
            res = res * base % m
        base = base * base % m
        b >>= 1
    return str(res).zfill(k)

print(last_k_digits(2, 50, 3))   # 2^50=1125899906842624 -> 624
print(last_k_digits(7, 7, 2))    # 7^7=823543 -> 43
```

> **复杂度**：O(log b) 时间，O(1) 空间

#### 12.12.3 例 54：模数运算表达式求值（OI）⭐⭐

> **知识点**：栈、运算符优先级、模运算｜**难度**：⭐⭐（中等）｜**类型**：OI/模运算应用

**思路**

💡 类比"先乘除后加减，乘法用栈压在一起"：表达式只含 `+` 与 `*`。维护一个栈——遇 `+` 把当前数压栈，遇 `*` 就把栈顶与当前数相乘后放回，保证**乘法先于加法结合**。最后对栈内所有数求和并取模即可（本例仅演示 `+`、`*` 两种运算符）。

```python
def eval_expr_mod(expr, mod):
    tokens = expr.split()
    stack = [int(tokens[0]) % mod]     # 首个操作数入栈
    i = 1
    while i < len(tokens):
        op = tokens[i]; i += 1
        v = int(tokens[i]) % mod; i += 1
        if op == '*':
            stack[-1] = stack[-1] * v % mod   # 乘法就近结合
        else:                                 # '+'
            stack.append(v)
    return sum(stack) % mod

print(eval_expr_mod("3 + 2 * 4", 10))    # 11 -> 1
print(eval_expr_mod("2 * 6 * 7", 100))   # 84
print(eval_expr_mod("1 + 2 + 3", 7))     # 6
```

> **复杂度**：O(L) 时间，O(L) 空间（L 为 token 数）

### 12.13 矩阵

> 涵盖：旋转图像、行列式计算、矩阵快速幂加速斐波那契。

#### 12.13.1 例 55：旋转图像（LeetCode 48）⭐⭐

> **知识点**：矩阵转置、对称交换｜**难度**：⭐⭐（中等）｜**类型**：LeetCode/矩阵

**思路**

💡 类比"先正着一折，再反着一折"：把矩阵顺时针旋转 90° 等价于两步——**沿主对角线转置**（把每个元素与对称位置的元素交换），再**把每一行反转**。两步都是就地 O(1) 额外空间完成。

```python
def rotate(matrix):
    """顺时针旋转矩阵 90°（原地）"""
    n = len(matrix)
    for i in range(n):                      # 1) 沿主对角线转置
        for j in range(i + 1, n):
            matrix[i][j], matrix[j][i] = matrix[j][i], matrix[i][j]
    for row in matrix:                      # 2) 每行反转
        row.reverse()

m = [[1, 2, 3], [4, 5, 6], [7, 8, 9]]
rotate(m)
print(m)   # [[7,4,1],[8,5,2],[9,6,3]]
```

> **复杂度**：O(n²) 时间，O(1) 空间

#### 12.13.2 例 56：行列式计算（按定义展开，OI）⭐⭐

> **知识点**：递归展开、代数余子式｜**难度**：⭐⭐（中等）｜**类型**：OI/线性代数

**思路**

💡 类比"按第一行摊开成更小矩阵"：行列式按第一行展开 `det = Σ (-1)^j · a[0][j] · det(余子式)`，其中余子式是删掉第 0 行与第 j 列后的子矩阵。对 n=1、n=2 直接返回，其余递归计算。

```python
def determinant(m):
    n = len(m)
    if n == 1:
        return m[0][0]
    if n == 2:
        return m[0][0] * m[1][1] - m[0][1] * m[1][0]
    det = 0
    for j in range(n):
        sub = [row[:j] + row[j + 1:] for row in m[1:]]   # 余子式
        det += ((-1) ** j) * m[0][j] * determinant(sub)
    return det

print(determinant([[2, 3], [1, 4]]))               # 5
print(determinant([[1, 2, 3], [4, 5, 6], [7, 8, 10]]))  # -3
```

> **复杂度**：O(n!) 时间，O(n²) 空间（递归，仅适合小 n）

#### 12.13.3 例 57：矩阵快速幂加速斐波那契（OI）⭐⭐⭐

> **知识点**：矩阵乘法、快速幂、斐波那契｜**难度**：⭐⭐⭐（困难）｜**类型**：OI/矩阵

**思路**

💡 类比"把递推式打包成一个 2×2 矩阵，再对它做快速幂"：`[F[n], F[n-1]] = M^(n-1) · [F[1], F[0]]`，其中 `M=[[1,1],[1,0]]`。把标量快速幂搬到矩阵上，即可把求斐波那契第 n 项从 O(n) 降到 O(log n)。

```python
def mat_mul(A, B, mod):
    n, m, K = len(A), len(B[0]), len(B)
    C = [[0] * m for _ in range(n)]
    for i in range(n):
        for k in range(K):
            if A[i][k]:
                aik = A[i][k]
                for j in range(m):
                    C[i][j] = (C[i][j] + aik * B[k][j]) % mod
    return C

def mat_pow(M, p, mod):
    n = len(M)
    R = [[1 if i == j else 0 for j in range(n)] for i in range(n)]
    while p:
        if p & 1:
            R = mat_mul(R, M, mod)
        M = mat_mul(M, M, mod)
        p >>= 1
    return R

def fib(n, mod):
    if n == 0:
        return 0
    M = [[1, 1], [1, 0]]
    Mn = mat_pow(M, n - 1, mod)
    return Mn[0][0] % mod

print(fib(10, 10 ** 9 + 7))   # 55
print(fib(50, 10 ** 9 + 7))
```

> **复杂度**：O(log n) 时间（常数大小的矩阵乘法），O(1) 空间

### 12.14 序列数学

#### 12.14.1 例 58：第 N 个泰波那契数（LeetCode 1137）⭐

> **知识点**：递推、滚动数组｜**难度**：⭐（简单）｜**类型**：LeetCode/序列

**思路**

💡 类比"三角递推，一人管三项"：泰波那契 `T(n)=T(n-1)+T(n-2)+T(n-3)`，初值 `T0=0,T1=1,T2=1`。用三个滚动变量递推，只需 O(1) 空间即可算出第 n 项。

```python
def tribonacci(n):
    t0, t1, t2 = 0, 1, 1
    if n < 3:
        return [0, 1, 1][n]
    for _ in range(3, n + 1):
        t0, t1, t2 = t1, t2, t0 + t1 + t2
    return t2

print(tribonacci(4))    # T3=2, T4=4
print(tribonacci(25))   # 1389537
print(tribonacci(37))
```

> **复杂度**：O(n) 时间，O(1) 空间

#### 12.14.2 例 59：连续正整数的和的数量（OI）⭐⭐

> **知识点**：等差数列、约数｜**难度**：⭐⭐（中等）｜**类型**：OI/序列数学

**思路**

💡 类比"枚举项数 k，把首项反解出来"：连续 k 个整数 `a..a+k-1` 的和为 `k·(2a+k-1)/2 = n`。枚举每种长度 k，若能解出整数首项 `a≥1`（即 `2a = 2n/k - (k-1)` 为正偶且 `a≥1`），就算一种方案。这等价于统计 n 的奇约数个数。

```python
def count_consecutive_sums(n):
    cnt = 0
    for k in range(1, n + 1):                 # 枚举长度
        s2 = 2 * n
        if s2 % k:
            continue
        t = s2 // k - (k - 1)                 # t = 2a
        if t > 0 and t % 2 == 0 and t >= 2:   # a >= 1
            cnt += 1
    return cnt

print(count_consecutive_sums(15))   # 4 : 15, 7+8, 4+5+6, 1+2+3+4+5
print(count_consecutive_sums(9))    # 3 : 9, 4+5, 2+3+4
```

> **复杂度**：O(n) 时间，O(1) 空间

#### 12.14.3 例 60：旋转数字（LeetCode 788）⭐⭐

> **知识点**：数位、映射、计数｜**难度**：⭐⭐（中等）｜**类型**：LeetCode/数位

**思路**

💡 类比"数字转 180° 看是否变样"：合法旋转的数字只能是 `0,1,2,5,6,8,9`（`2↔5,6↔9`），含 `3,4,7` 一律非法；若旋转后与原数不同（至少含 `2,5,6,9` 之一）就是"好数"。直接枚举 1..n 按位判断计数。

```python
def rotated_digits(n):
    bad = set('347')
    change = set('2569')
    cnt = 0
    for x in range(1, n + 1):
        s = str(x)
        ok, changed = True, False
        for ch in s:
            if ch in bad:
                ok = False
                break
            if ch in change:
                changed = True
        if ok and changed:
            cnt += 1
    return cnt

print(rotated_digits(10))    # 4  (2,5,6,9)
print(rotated_digits(25))
```

#### 12.14.4 例 61：约瑟夫环（LeetCode 1823 / OI）⭐⭐

> **知识点**：递推、取模｜**难度**：⭐⭐（中等）｜**类型**：OI/序列数学

**思路**

💡 类比"倒着从 1 人反推回去"：设 `f(n)` 为 n 人、每数 k 个出圈，最后幸存者的 0 下标。删掉第 k 个人后，问题由 n-1 人递推而来，且编号整体平移了 k，故 `f(n)=(f(n-1)+k) % n`，边界 `f(1)=0`。从 1 迭代到 n 即得答案。

```python
def josephus(n, k):
    pos = 0                       # 1 人时的幸存者下标
    for i in range(2, n + 1):
        pos = (pos + k) % i
    return pos                    # 返回 0 下标幸存者

print(josephus(7, 3))    # 3  （即第 4 个人，1 下标）
print(josephus(5, 2))    # 2  （0 下标）
```

### 12.15 概率与期望

> 涵盖：几何分布首中期望、三门问题、公平掷币到指定状态的期望步数。

#### 12.15.1 例 62：几何分布·首中期望（OI）⭐⭐

> **知识点**：几何分布、期望、蒙特卡洛｜**难度**：⭐⭐（中等）｜**类型**：OI/概率期望

**思路**

💡 类比"想等到第一朵花开花，平均要等 1/p 次"：每次独立成功概率为 p 的试验，首次成功所需的试验次数服从**几何分布**，其期望恰为 `1/p`（如 `P(首次在第 k 次)=p(1-p)^(k-1)`）。用大样本模拟逼近验证。

```python
import random

def first_success_sim(p, trials=200000):
    total = 0
    for _ in range(trials):
        flips = 0
        while True:
            flips += 1
            if random.random() < p:
                break
        total += flips
    return total / trials

print("模拟期望:", round(first_success_sim(0.2), 3))  # 约 5.0
print("理论值 1/p:", 1 / 0.2)                          # 5.0
```

> **复杂度**：O(trials / p) 时间，O(1) 空间

#### 12.15.2 例 63：三门问题·蒙提霍尔（OI）⭐⭐

> **知识点**：条件概率、枚举模拟｜**难度**：⭐⭐（中等）｜**类型**：OI/概率

**思路**

💡 类比"主持人帮你剔除一个错误门，等于变相把两个门的机会并给你"：主持人总会打开一扇没车的门后让你选择换。不换的中奖率固定 1/3，而换门等价于"picked 之外的两扇中至少一扇有车"，即 2/3。用枚举模拟验证。

```python
import random

def monty_hall(trials=200000):
    win_keep = win_swap = 0
    for _ in range(trials):
        car = random.randrange(3)
        pick = random.randrange(3)
        goats = [d for d in range(3) if d != car and d != pick]
        opened = random.choice(goats)                       # 主持人开门
        remaining = [d for d in range(3) if d != pick and d != opened][0]
        win_keep += (pick == car)
        win_swap += (remaining == car)
    return win_keep / trials, win_swap / trials

keep, swap = monty_hall()
print("坚持:", round(keep, 3), " 换门:", round(swap, 3))  # 约 0.333 / 0.667
```

> **复杂度**：O(trials) 时间，O(1) 空间

#### 12.15.3 例 64：公平掷币·期望步数（OI）⭐⭐⭐

> **知识点**：期望递推、线性方程｜**难度**：⭐⭐⭐（困难）｜**类型**：OI/概率期望进阶

**思路**

💡 类比"用状态方程解期望，等号两边都含未知量"：设 `E0` 为从零开始掷出「连续两个正面 HH」的期望次数，`E1` 为已掷出一个正面后还需掷的次数。写出 `E0 = 1 + ½·E1 + ½·E0`（第一掷为正面进入状态 1，反面回到起点），`E1 = 1 + ½·0 + ½·E0`（正面即完成，反面重置）。解得 `E1=4, E0=6`。

```python
import random

def expected_hh():
    # 解线性方程:
    # E1 = 1 + 0.5*E0
    # E0 = 1 + 0.5*E1 + 0.5*E0  => E0 = 2 + E1
    # 代入得 E1 = 4, E0 = 6
    return 6.0

def simulate(trials=200000):
    total = 0
    for _ in range(trials):
        flips, streak = 0, 0
        while True:
            flips += 1
            streak = streak + 1 if random.random() < 0.5 else 0
            if streak == 2:
                break
        total += flips
    return total / trials

print("解析期望:", expected_hh())                       # 6.0
print("模拟期望:", round(simulate(), 3))                # 约 6.0
```

> **复杂度**：O(trials) 时间（解析解 O(1)），O(1) 空间

### 12.16 计算几何进阶

> 涵盖：多边形面积（鞋带公式）、线段相交判定、两圆相交面积、点与凸多边形位置、最小覆盖圆（随机增量法）。

#### 12.16.1 例 65：多边形面积·鞋带公式（OI）⭐

> **知识点**：鞋带公式、叉积｜**难度**：⭐（简单）｜**类型**：OI/计算几何

**思路**

💡 类比"把多边形拆成从原点出发的三角形，有正有负地相加"：按顶点顺序累加 `Σ (x[i]·y[i+1] - x[i+1]·y[i])`，取绝对值的一半即面积。这就是**鞋带公式**，对凸/凹多边形均成立。

```python
def polygon_area(points):
    """points: 按顺序排列的 (x,y) 顶点列表"""
    s = 0
    n = len(points)
    for i in range(n):
        x1, y1 = points[i]
        x2, y2 = points[(i + 1) % n]
        s += x1 * y2 - x2 * y1
    return abs(s) / 2

print(polygon_area([(0, 0), (4, 0), (4, 3), (0, 3)]))   # 12
print(polygon_area([(0, 0), (2, 0), (1, 1)]))           # 1
```

> **复杂度**：O(n) 时间，O(1) 空间

#### 12.16.2 例 66：线段相交判定（跨立实验，OI）⭐⭐

> **知识点**：叉积、跨立实验、向量｜**难度**：⭐⭐（中等）｜**类型**：OI/计算几何

**思路**

💡 类比"两条线在平面上互相'跨立'来判断是否相交"：对于两条线段 `p1p2`、`p3p4`，用叉积判断——若 `p3,p4` 分别位于 `p1p2` 两侧，且 `p1,p2` 分别位于 `p3p4` 两侧，则相交；叉积为 0 时再用点在线上判断退化（共线/端点）情形。

```python
class Point:
    def __init__(self, x, y):
        self.x, self.y = x, y

def cross(a, b, c):
    return (b.x - a.x) * (c.y - a.y) - (b.y - a.y) * (c.x - a.x)

def on_segment(a, b, p):
    return (min(a.x, b.x) <= p.x <= max(a.x, b.x) and
            min(a.y, b.y) <= p.y <= max(a.y, b.y))

def seg_intersect(p1, p2, p3, p4):
    d1, d2 = cross(p3, p4, p1), cross(p3, p4, p2)
    d3, d4 = cross(p1, p2, p3), cross(p1, p2, p4)
    if ((d1 > 0 and d2 < 0) or (d1 < 0 and d2 > 0)) and \
       ((d3 > 0 and d4 < 0) or (d3 < 0 and d4 > 0)):
        return True
    if d1 == 0 and on_segment(p3, p4, p1): return True   # 退化情形
    if d2 == 0 and on_segment(p3, p4, p2): return True
    if d3 == 0 and on_segment(p1, p2, p3): return True
    if d4 == 0 and on_segment(p1, p2, p4): return True
    return False

print(seg_intersect(Point(0,0),Point(2,2),Point(0,2),Point(2,0)))  # True 十字
print(seg_intersect(Point(0,0),Point(1,1),Point(2,2),Point(3,3)))  # False 平行
```

> **复杂度**：O(1) 时间，O(1) 空间

#### 12.16.3 例 67：两圆相交面积（OI）⭐⭐

> **知识点**：扇形、三角形、反三角函数｜**难度**：⭐⭐（中等）｜**类型**：OI/计算几何

**思路**

💡 类比"两个扇形扣掉两个三角形拼出重叠部分"：设两圆半径 `r1,r2`、圆心距 `d`。若 `d ≥ r1+r2` 不相交；若 `d ≤ |r1-r2|` 小圆被完全包含。否则用余弦定理求出每个圆心对应的夹角 `a1,a2`，相交面积 `= r1²(a1−sin a1 cos a1) + r2²(a2−sin a2 cos a2)`。

```python
import math

def circle_inter_area(x1, y1, r1, x2, y2, r2):
    d = math.hypot(x1 - x2, y1 - y2)
    if d >= r1 + r2:
        return 0.0
    if d <= abs(r1 - r2):                       # 完全包含
        return math.pi * min(r1, r2) ** 2
    a1 = math.acos((r1 * r1 + d * d - r2 * r2) / (2 * r1 * d))
    a2 = math.acos((r2 * r2 + d * d - r1 * r1) / (2 * r2 * d))
    return (r1 * r1 * (a1 - math.sin(a1) * math.cos(a1)) +
            r2 * r2 * (a2 - math.sin(a2) * math.cos(a2)))

print(round(circle_inter_area(0, 0, 1, 0, 0, 1), 5))     # 重合 -> π
print(round(circle_inter_area(0, 0, 1, 3, 0, 1), 5))     # 相离 -> 0
print(round(circle_inter_area(0, 0, 1, 1, 0, 1), 5))     # 相切点 -> 有重叠
```

> **复杂度**：O(1) 时间，O(1) 空间

#### 12.16.4 例 68：点是否在凸多边形内（OI）⭐⭐

> **知识点**：叉积、凸多边形｜**难度**：⭐⭐（中等）｜**类型**：OI/计算几何

**思路**

💡 类比"绕凸多边形走一圈，看点是总在左边还是割裂两半"：凸多边形（顶点逆时针排）内的点，对每条边叉积 `(b-a)×(p-a)` 符号一致（均 ≥0 或均 ≤0）。若所有叉积同号（或某边叉积为 0 且点落在边上）即在内部/边上。

```python
def cross(o, a, b):
    return (a[0] - o[0]) * (b[1] - o[1]) - (a[1] - o[1]) * (b[0] - o[0])

def in_convex_polygon(poly, p):
    n = len(poly)
    sign = 0
    for i in range(n):
        a, b = poly[i], poly[(i + 1) % n]
        cr = cross(a, b, p)
        if cr == 0:                                  # 点可能在边所在直线上
            if min(a[0], b[0]) <= p[0] <= max(a[0], b[0]) and \
               min(a[1], b[1]) <= p[1] <= max(a[1], b[1]):
                return True                          # 恰好在边上
            continue
        cur = 1 if cr > 0 else -1
        if sign == 0:
            sign = cur
        elif sign != cur:
            return False
    return True

poly = [(0, 0), (4, 0), (4, 4), (0, 4)]
print(in_convex_polygon(poly, (2, 2)))   # True  内部
print(in_convex_polygon(poly, (5, 2)))   # False 外部
print(in_convex_polygon(poly, (4, 2)))   # True  边上
```

> **复杂度**：O(n) 时间，O(1) 空间

#### 12.16.5 例 69：最小覆盖圆（随机增量法，OI）⭐⭐⭐

> **知识点**：三点定圆、随机化、增量法｜**难度**：⭐⭐⭐（困难）｜**类型**：OI/计算几何进阶

**思路**

💡 类比"先随便定个小圆，发现有点在外圈就强行把它纳入再扩张"：随机打乱点集后逐个检查——若当前点在圆内则继续，否则以该点为圆上的点重新构造：先找第二个点定直径圆，再找第三个点跳过共线情形用三点定圆。经随机化后期望复杂度 O(n)，最坏 O(n³)。

```python
import math, random

def in_circle(c, p):
    return math.hypot(c[0] - p[0], c[1] - p[1]) <= c[2] + 1e-9

def two_point(a, b):                        # 以 a,b 为直径
    return ((a[0] + b[0]) / 2, (a[1] + b[1]) / 2,
            math.hypot(a[0] - b[0], a[1] - b[1]) / 2)

def three_point(a, b, c):                   # 三点外接圆
    ax, ay = a; bx, by = b; cx, cy = c
    d = 2 * (ax * (by - cy) + bx * (cy - ay) + cx * (ay - by))
    if abs(d) < 1e-12:                      # 共线：取最远两点直径
        return max([two_point(a, b), two_point(b, c), two_point(a, c)],
                   key=lambda q: q[2])
    ux = ((ax*ax+ay*ay)*(by-cy) + (bx*bx+by*by)*(cy-ay) + (cx*cx+cy*cy)*(ay-by)) / d
    uy = ((ax*ax+ay*ay)*(cx-bx) + (bx*bx+by*by)*(ax-cx) + (cx*cx+cy*cy)*(bx-ax)) / d
    return (ux, uy, math.hypot(ux - ax, uy - ay))

def min_enclosing_circle(points):
    pts = points[:]
    random.shuffle(pts)
    c = (pts[0][0], pts[0][1], 0.0)
    for i, p in enumerate(pts[1:], 1):
        if in_circle(c, p):
            continue
        c = (p[0], p[1], 0.0)                       # 新点必在最终圆上
        for j in range(i):
            q = pts[j]
            if in_circle(c, q):
                continue
            c = two_point(p, q)
            for k in range(j):
                r = pts[k]
                if in_circle(c, r):
                    continue
                c = three_point(p, q, r)
    return c

pts = [(0, 0), (2, 0), (1, 1), (0, 2)]
cx, cy, r = min_enclosing_circle(pts)
print(round(cx, 4), round(cy, 4), round(r, 4))   # ~1.0 1.0 1.4142
```

> **复杂度**：期望 O(n)、最坏 O(n³) 时间，O(1) 空间

#### 12.17.1 例 70：短板原理·最小均衡操作（OI）⭐

> **知识点**：贪心、最优化｜**难度**：⭐（简单）｜**类型**：OI/数学证明

**思路**

💡 类比"木桶装水量由最短的那块板决定"：要让数组所有元素相等，只能做"任选一个元素减 1"的操作，那么最大值必须一直降到 `min` 一格。最优步数就是把所有元素都削到最小值，即 `sum - n * min`——因为短板不能更低，均衡目标只能取 min。

```python
def min_ops_equalize(a):
    return sum(a) - len(a) * min(a)

print(min_ops_equalize([1, 2, 3]))    # 3   （3->1 两步, 2->1 一步）
print(min_ops_equalize([1, 5, 5]))    # 4
```

#### 12.17.2 例 71：鸽巢原理·第一个缺失的正数（LeetCode 41，OI 构造）⭐⭐

> **知识点**：鸽巢原理、下标映射、交换原地哈希｜**难度**：⭐⭐（中等）｜**类型**：OI/数学证明

**思路**

💡 类比"把每个数送到属于它自己的'鸽笼'下标"：对于长为 n 的数组，缺失的最小正数最多是 n+1，可能性都在 `1..n`。用**原地交换**把 `i` 放到位 `i-1`（值在 `1..n` 且未就位），最后扫一遍，第一个 `nums[i] != i+1` 的位置即答案。

```python
def first_missing_positive(nums):
    n = len(nums)
    nums = list(nums)
    for i in range(n):
        while 1 <= nums[i] <= n and nums[nums[i] - 1] != nums[i]:
            v = nums[i]
            nums[v - 1], nums[i] = nums[i], nums[v - 1]
    for i in range(n):
        if nums[i] != i + 1:
            return i + 1
    return n + 1

print(first_missing_positive([3, 4, -1, 1]))   # 2
print(first_missing_positive([1, 2, 0]))       # 3
print(first_missing_positive([1, 2, 3]))       # 4
```

> **复杂度**：O(n) 时间，O(1) 额外空间

#### 12.17.3 例 72：构造·Zeckendorf 斐波那契表示（OI）⭐⭐

> **知识点**：贪心构造、斐波那契数列｜**难度**：⭐⭐（中等）｜**类型**：OI/数学构造

**思路**

💡 类比"从大到小贪心拆金币"：Zeckendorf 定理保证任意正整数都能唯一表成**若干不相邻的斐波那契数**之和。做法是取比 n 大的最小斐波那契数列表，然后**从大到小贪心**：能减就减，所得即表示（相邻不能同取，贪心自然保证该性质）。

```python
def zeckendorf(n):
    fib = [1, 2]
    while fib[-1] <= n:
        fib.append(fib[-1] + fib[-2])
    res = []
    for f in reversed(fib[:-1]):
        if n >= f:
            res.append(f)
            n -= f
    return res

print(zeckendorf(100))   # [89, 8, 3]
print(zeckendorf(30))    # [21, 8, 1]
print(sum(zeckendorf(12345)) == 12345)   # True 自校验
```

> **复杂度**：O(log n) 时间，O(log n) 空间

#### 12.17.4 例 73：构造·最大数拼接（LeetCode 179）⭐⭐⭐

> **知识点**：自定义排序、贪心构造、比较交换｜**难度**：⭐⭐⭐（困难）｜**类型**：OI/数学构造

**思路**

💡 类比"两个数谁放前面更大，就让谁站前面"：为把数字拼成最大数，定义比较——`a` 排 `b` 前面当且仅当 `a+b > b+a`（字符串拼接后字典序更大）。用该自定义规则排序后拼接；若结果以 '0' 开头（全零）则返回 "0"。

```python
import functools

def comparator(a, b):
    if a + b > b + a:
        return -1
    if a + b < b + a:
        return 1
    return 0

def largest_number(nums):
    arr = [str(x) for x in nums]
    arr.sort(key=functools.cmp_to_key(comparator))
    res = ''.join(arr)
    return '0' if res[0] == '0' else res

print(largest_number([3, 30, 34, 5, 9]))   # 9534330
print(largest_number([0, 0]))              # 0
print(largest_number([121, 12]))           # 12121
```

> **复杂度**：O(n log n) 时间，O(n) 空间

#### 12.18.1 例 74：自守数（OI）⭐

**思路**

💡 类比"照镜子，镜子里的数字尾巴和自己一样"：自守数（automorphic number）满足 `n²` 的末几位恰好等于 `n`。把 `n` 和 `n²` 都转成字符串，判断 `n` 的字符串是否为 `n²` 字符串的后缀即可。

```python
def automorphic(n):
```

#### 12.18.2 例 75：阿姆斯特朗数（自恋数，OI）⭐

> **知识点**：数位拆分、幂运算｜**难度**：⭐（简单）｜**类型**：OI/数论

**思路**

💡 类比"每个数字拿着它的'位数次方'来拼自己"：一个 n 位数若是阿姆斯特朗数，则它等于各数位"数位次方"之和。逐位拆分计算即可；也可一次筛出区间内所有阿姆斯特朗数。

```python
def is_armstrong(n):
    s = str(n)
    p = len(s)
    return sum(int(d) ** p for d in s) == n

def armstrong_below(limit):
    return [k for k in range(limit) if is_armstrong(k)]

print(is_armstrong(153))        # True  1³+5³+3³=153
print(is_armstrong(9474))       # True  9⁴+4⁴+7⁴+4⁴=9474
print(is_armstrong(12))         # False
print(armstrong_below(1000))    # [0,1,2,3,...,153,370,371,407]
```

> **复杂度**：O(log n) 时间，O(1) 空间

#### 12.18.3 例 76：数码和与数根（OI）⭐

> **知识点**：数位求和、数根公式｜**难度**：⭐（简单）｜**类型**：OI/数论

**思路**

💡 类比"把一堆珠子反复重新数成一位"：数根（digital root）是把各位数字相加直到得到一位数，等价于 `1 + (n-1) % 9`。区间数码和问题可预处理前缀和：`f(l..r) = prefix[r] - prefix[l-1]`。

```python
def digit_sum(n):
    return sum(map(int, str(n)))

def digital_root(n):
    return 1 + (n - 1) % 9 if n else 0

# 区间 [l, r] 数码和：前缀和预处理
def range_digit_sum(prefix, l, r):
    return prefix[r] - prefix[l - 1]

n = 12345
prefix = [0] * (n + 1)
for i in range(1, n + 1):
    prefix[i] = prefix[i - 1] + digit_sum(i)

print(digital_root(9875))                 # 2   9+8+7+5=29 -> 2+9=11 -> 2
print(digit_sum(2024))                    # 8
print(range_digit_sum(prefix, 1, 9))      # 45  1..9 数码和
print(range_digit_sum(prefix, 10, 20))    # 110  (1+0)+...+(2+0)
```

> **复杂度**：O(log n)（单次数根），O(n)（预处理区间和）空间 O(n)

### 12.19 数位反转变体与进制

> 涵盖：整数反转、进制转换（七进制）、数位哈希指纹。

#### 12.19.1 例 77：整数反转（LeetCode 7）⭐

> **知识点**：数位拆分、溢出处理｜**难度**：⭐（简单）｜**类型**：OI/数位

**思路**

💡 类比"倒着把数位一个一个喂进新数"：反复 `pop = x % 10`，再 `x //= 10`，同时 `res = res*10 + pop`。溢出可用上界判断：新数超过 `2^31-1` 或小于 `-2^31` 时返回 0。

```python
def reverse_int(x):
    sign = 1 if x >= 0 else -1
    x = abs(x)
    res = 0
    while x:
        res = res * 10 + x % 10
        x //= 10
    res *= sign
    return res if -2**31 <= res <= 2**31 - 1 else 0

print(reverse_int(1234))    # 4321
print(reverse_int(-120))    # -21
print(reverse_int(1534236469))  # 0  反转后溢出
```

> **复杂度**：O(log n) 时间，O(1) 空间

#### 12.19.2 例 78：七进制数（LeetCode 504）⭐

> **知识点**：进制转换、负数处理｜**难度**：⭐（简单）｜**类型**：OI/进制

**思路**

💡 类比"按重量打包货物，7 个一组继续打包"：除基取余法——反复除 7 取余，逆序拼接即得七进制。负数先取绝对值转正，最后补符号。

```python
def to_base7(n):
    if n == 0:
        return "0"
    sign = "-" if n < 0 else ""
    n = abs(n)
    digits = []
    while n:
        n, r = divmod(n, 7)
        digits.append(str(r))
    return sign + "".join(reversed(digits))

print(to_base7(100))    # "202"   100=2*49+0*7+2
print(to_base7(-7))     # "-10"
print(to_base7(0))      # "0"
```

> **复杂度**：O(log₇ n) 时间，O(log₇ n) 空间

#### 12.19.3 例 79：数位哈希·数字重排判断（OI）⭐⭐

> **知识点**：哈希、频数统计｜**难度**：⭐⭐（中等）｜**类型**：OI/哈希数字

**思路**

💡 类比"给每个数字发一个'指纹'，指纹相同就是同伙"：判断两个数是否互为数位重排（permutation），无需排序，直接用大小为 10 的桶统计各数位出现次数作哈希指纹对比即可，O(L) 优于排序的 O(L log L)。

```python
def digit_fingerprint(n):
    cnt = [0] * 10
    for ch in str(abs(n)):
        cnt[int(ch)] += 1
    return tuple(cnt)      # 10 元组作哈希指纹

def same_digits(a, b):
    return digit_fingerprint(a) == digit_fingerprint(b)

print(same_digits(123, 321))     # True
print(same_digits(2024, 4202))   # True
print(same_digits(123, 124))     # False
```

> **复杂度**：O(l₁ + l₂) 时间，O(10) 空间

### 12.20 分数运算·容积·周长

> 涵盖：分数加减化简、双指针容积、多边形周长。

#### 12.20.1 例 80：分数加减法·最简运算（OI）⭐⭐

> **知识点**：欧几里得算法、通分模拟｜**难度**：⭐⭐（中等）｜**类型**：OI/分数运算

**思路**

💡 类比"腾挪不同分母的盘子先找一个共同大小"：通分后合并分子，再用 gcd 约分到最简。注意负数与符号处理，保证分母为正。

```python
from math import gcd

def frac_add(fracs):
    """fracs: [(num, den), ...] 返回最简 (num, den)"""
    num, den = 0, 1
    for v, d in fracs:
        nd = den * d               # 通分
        num = num * d + v * den
        den = nd
        g = gcd(num, den)          # 约分
        num //= g
        den //= g
    if den < 0:
        num, den = -num, -den
    return num, den

print(frac_add([(1, 2), (1, 3)]))    # (5, 6)
print(frac_add([(1, 2), (1, 4), (1, 4)]))  # (1, 1)
print(frac_add([(1, 3), (-1, 6)]))   # (1, 6)
```

> **复杂度**：O(k·log V) 时间，O(1) 空间

#### 12.20.2 例 81：容积·盛最多水（LeetCode 11）⭐⭐

> **知识点**：双指针、贪心｜**难度**：⭐⭐（中等）｜**类型**：OI/容积变体

**思路**

💡 类比"两只手从两端往里收，短的那边移动才可能装更多"：面积 = `min(h[l], h[r]) * (r-l)`。固定最宽两端，总是移动**较短**的一根，因为短板决定上限，这保证不会错过更大的面积。

```python
def max_area(height):
    l, r = 0, len(height) - 1
    best = 0
    while l < r:
        area = min(height[l], height[r]) * (r - l)
        best = max(best, area)
        if height[l] < height[r]:
            l += 1
        else:
            r -= 1
    return best

print(max_area([1, 8, 6, 2, 5, 4, 8, 3, 7]))  # 49
print(max_area([1, 1]))                        # 1
```

> **复杂度**：O(n) 时间，O(1) 空间

#### 12.20.3 例 82：多边形周长（两点距离累加，OI）⭐

> **知识点**：欧氏距离、环形累加｜**难度**：⭐（简单）｜**类型**：OI/几何周长

**思路**

💡 类比"沿着一圈围墙一步再一步走回家"：多边形周长是各相邻顶点连线的长度之和，最后要加上最后一个顶点到第一个顶点的边。

```python
def perimeter(points):
    dist = lambda a, b: ((a[0]-b[0])**2 + (a[1]-b[1])**2) ** 0.5
    total = 0.0
    n = len(points)
    for i in range(n):
        total += dist(points[i], points[(i + 1) % n])
    return total

# 边长为3的正方形
print(perimeter([(0, 0), (3, 0), (3, 3), (0, 3)]))   # 12.0
print(perimeter([(0, 0), (4, 0)]))                   # 8.0  (退化为线段,来回)
```

> **复杂度**：O(n) 时间，O(1) 空间

#### 12.21.3 例 85：向量·点积与夹角（OI）⭐⭐

**思路**

💡 类比"两个向量的'同向程度'用点积衡量"：点积 `a·b = x1x2 + y1y2 = |a||b|cosθ`。由 `cosθ = dot / (|a||b|)` 反解夹角，并可用叉积判断转向方向。

```python
import math

def dot(a, b):
    return a[0] * b[0] + a[1] * b[1]

def cross(a, b):
    return a[0] * b[1] - a[1] * b[0]

def norm(v):
    return (v[0] ** 2 + v[1] ** 2) ** 0.5

def angle_deg(a, b):
    c = dot(a, b) / (norm(a) * norm(b))
    return math.degrees(math.acos(max(-1, min(1, c))))

print(round(angle_deg((1, 0), (0, 1)), 3))     # 90.0
print(round(angle_deg((1, 1), (1, 0)), 3))     # 45.0
```

### 12.22 数论应用：LCM 创建与同余计数

> 涵盖：最小公倍数创建、区间同余计数。

#### 12.22.1 例 87：最小公倍数·创建最小可整除数（OI）⭐⭐

> **知识点**：GCD/LCM、数论应用｜**难度**：⭐⭐（中等）｜**类型**：OI/数论应用

**思路**

💡 类比"找两个齿轮齿数的'公共啮合点'"：最小公倍数 `lcm(a,b) = a·b // gcd(a,b)`。推广到 `1..k` 的 LCM，一个数若能同时被它们整除，必是 LCM 的倍数；求区间内"被 a、b 整除"的最小数即 `lcm` 本身。

```python
from math import gcd

def lcm(a, b):
    return a // gcd(a, b) * b

def lcm_1_to_k(k):
    res = 1
    for i in range(2, k + 1):
        res = lcm(res, i)
    return res

def smallest_divisible(a, b, limit):
    v = lcm(a, b)
    return v if v <= limit else -1

print(lcm(4, 6))                          # 12
print(lcm_1_to_k(10))                     # 2520  1..10 都能整除 2520
print(smallest_divisible(9, 25, 1000))    # 225
print(smallest_divisible(100, 200, 100))  # -1  超限
```

> **复杂度**：O(k·log V) 时间，O(1) 空间

#### 12.22.2 例 88：同余·区间内 ≡ b (mod c) 的整数（OI）⭐

> **知识点**：同余、等差数列计数｜**难度**：⭐（简单）｜**类型**：OI/模运算

**思路**

💡 类比"每隔固定间隔取值"：满足 `x ≡ b (mod c)` 的数构成公差为 c 的等差数列。给定区间 `[lo, hi]`，用差除法统计落点个数即可，无需枚举。

```python
def count_congruent(lo, hi, b, c):
    """统计 [lo,hi] 中形如 b + k*c 的整数个数"""
    if c == 0:
        return 1 if lo <= b <= hi else 0
    start = b + ((lo - b + c - 1) // c) * c  # 向上取整到解
    if start > hi:
        return 0
    return (hi - start) // c + 1

print(count_congruent(1, 100, 3, 5))    # 20: 3,8,...,98
print(count_congruent(10, 30, 1, 7))    # 3: 15,22,29
print(count_congruent(1, 10, 0, 4))     # 2: 4,8
```

### 12.23 求值引擎与复合函数

> 涵盖：后缀（RPN）表达式求值、复合函数嵌套、前缀表达式求值。

#### 12.23.1 例 89：后缀（RPN）表达式求值（LeetCode 150）⭐⭐

> **知识点**：栈、表达式求值｜**难度**：⭐⭐（中等）｜**类型**：OI/标准求值变体

**思路**

💡 类比"数字排队，一遇到运算符就和身后的两个数字碰头"：从左到右，遇到数字压栈，遇到运算符弹出两个数计算再压回。栈顶先进后出，注意除法与减法的先后。

```python
def eval_rpn(tokens):
    st = []
    for t in tokens:
        if t in ('+', '-', '*', '/'):
            b = st.pop()
            a = st.pop()
            if t == '+': st.append(a + b)
            elif t == '-': st.append(a - b)
            elif t == '*': st.append(a * b)
            else: st.append(int(a / b))   # 向零取整
        else:
            st.append(int(t))
    return st[0]

print(eval_rpn(["2", "1", "+", "3", "*"]))        # 9
print(eval_rpn(["4", "13", "5", "/", "+"]))        # 6
print(eval_rpn(["10", "6", "9", "3", "+", "-11", "*", "/", "*", "17", "+", "5", "+"]))  # 22
```

> **复杂度**：O(n) 时间，O(n) 空间

#### 12.23.2 例 90：复合函数·嵌套求值（OI）⭐⭐

> **知识点**：复合函数、函数表驱动｜**难度**：⭐⭐（中等）｜**类型**：OI/函数复合

**思路**

💡 类比"层层套娃，从最里层开始往外拆"：`f(g(h(x)))` 从内向外依次代入。可用函数对象表驱动，把函数名映射到可调用对象后按顺序复合。

```python
fns = {
    'double': lambda x: x * 2,
    'square': lambda x: x * x,
    'plus1': lambda x: x + 1,
}

def compose(names, x):
    """按 names 顺序从内到外复合: 先 names[0] 再依次"""
    val = x
    for fn in names:
        val = fns[fn](val)     # names[0] 作用在最里面
    return val

print(compose(['plus1', 'double'], 3))    # 8  =2*(3+1) = double(plus1(3))
print(compose(['square', 'plus1'], 4))    # 17 = (4+1)^2 = square(plus1(4))
```

#### 12.23.3 例 91：前缀表达式求值（OI）⭐⭐⭐

> **知识点**：栈、表达式顺序｜**难度**：⭐⭐⭐（困难）｜**类型**：OI/标准求值变体

**思路**

💡 类比"运算符在前，数字在后，从右往左反着压栈"：前缀表达式（波兰式）`+ * 3 4 2`。从右向左扫描，数字压栈，遇运算符弹出右、左操作数计算再压回。掌握它与后缀的对称关系即可轻松复用栈解法。

```python
import operator

def eval_prefix(tokens):
    ops = {'+': operator.add, '-': operator.sub,
           '*': operator.mul, '/': lambda a, b: int(a / b)}
    st = []
    for t in reversed(tokens):
        if t.isdigit() or (t[0] == '-' and len(t) > 1):
            st.append(int(t))
        else:
            l = st.pop()   # 反向扫描时先被弹出的反而是左边的操作数
            r = st.pop()
            st.append(ops[t](l, r))
    return st[0]

print(eval_prefix(['+', '*', '3', '4', '2']))   # 14 = 3*4+2
print(eval_prefix(['-', '10', '4']))             # 6
```

> **复杂度**：O(n) 时间，O(n) 空间

### 12.24 整除特征与快乐数变体

#### 12.24.1 例 92：整除特征·3/9/11 判别（OI）⭐

**思路**

💡 类比"用'残差法'快速判断整除而不做除法"：一个数能被 3 或 9 整除当且仅当各位数字和能被 3/9 整除；能被 11 整除当且仅当奇偶位数字和之差能被 11 整除。用于超大数的整除判断非常高效。

```python
def div_by_3_9_11(n):
    s = str(n)
    ds = sum(map(int, s))
    odd = sum(int(s[i]) for i in range(0, len(s), 2))
    even = sum(int(s[i]) for i in range(1, len(s), 2))
    return {

        'by9': ds % 9 == 0,
        'by11': (odd - even) % 11 == 0,
```

#### 12.24.2 例 93：快乐数变体·任意进制快乐过程（OI）⭐⭐

```python
def next_sq(n, base=10):
    s = 0
    while n:
        n, r = divmod(n, base)
        s += r * r
    return s

def is_happy(n, base=10):
    seen = set()
    while n != 1 and n not in seen:
        seen.add(n)
        n = next_sq(n, base)
    return n == 1

print(is_happy(19))      # True   19->82->68->100->1
print(is_happy(2))       # False
print(is_happy(5, 2))    # 二进制的5(=101) 检查
```

### 12.25 幂等式与根式

> 涵盖：一般幂判断、完全 k 次方幂、根式化简。

#### 12.25.1 例 94：判断 n 是否为 a^k（幂等式，OI）⭐⭐

> **知识点**：质因数分解、指数 gcd｜**难度**：⭐⭐（中等）｜**类型**：OI/幂等式

**思路**

💡 类比"把整数反复开方，看能否开出整数根"：判断 `n` 是否为某个整数的幂，可对 `n` 做质因数分解，检查所有质因数的指数之最大公约数 `g>1` 即可。

```python
import math

def factor_exponents(n):
    e = {}
    d = 2
    while d * d <= n:
        while n % d == 0:
            e[d] = e.get(d, 0) + 1
            n //= d
        d += 1 if d == 2 else 2
    if n > 1:
        e[n] = e.get(n, 0) + 1
    return e

def is_perfect_power(n):
    """是否存在整数 k>=2 使 n = a^k"""
    if n <= 1:
        return True
    g = 0
    for v in factor_exponents(n).values():
        g = math.gcd(g, v)
    return g >= 2

print(is_perfect_power(64))   # True  64=8^2=4^3=2^6
print(is_perfect_power(81))   # True  81=3^4
print(is_perfect_power(72))   # False 72=2^3*3^2, gcd(3,2)=1
```

> **复杂度**：O(√n) 时间，O(1) 空间

#### 12.25.2 例 95：根式化简 √n = a√b（OI）⭐⭐

> **知识点**：质因数分解、平方因子｜**难度**：⭐⭐（中等）｜**类型**：OI/根式化简

**思路**

💡 类比"把被开方数里的平方因子'整体搬'到根号外面"：`√n = a√b`，其中 `a` 是 `n` 的最大平方因子。做法是累乘 `n` 中成对的质因子形成 `a`，剩下的单个因子进入 `b`。

```python
def simplify_sqrt(n):
    """返回 (a, b) 使 √n = a·√b, b 无平方因子"""
    a, b = 1, 1
    d = 2
    while d * d <= n:
        cnt = 0
        while n % d == 0:
            n //= d
            cnt += 1
        a *= d ** (cnt // 2)   # 成对的质因子进 a
        if cnt % 2:
            b *= d             # 单个的进 b
        d += 1 if d == 2 else 2
    if n > 1:
        b *= n                 # 剩余一个质因子进 b
    return a, b

print(simplify_sqrt(72))    # (6, 2)   √72=6√2 (72=2³·3²)
print(simplify_sqrt(50))    # (5, 2)   √50=5√2
print(simplify_sqrt(16))    # (4, 1)
```

> **复杂度**：O(√n) 时间，O(1) 空间

#### 12.25.3 例 96：完全 k 次方幂判定（OI）⭐⭐⭐

> **知识点**：二分查找、整数幂｜**难度**：⭐⭐⭐（困难）｜**类型**：OI/幂等式

**思路**

💡 类比"推断一个数到底是不是某个整数的 k 次方"：判定 `n` 是否为完全 k 次方幂（存在整数 `a` 使 `aᵏ=n`）。用**整数二分**求精确的 `k` 次根（避免浮点误差），吻合即为完全幂。

```python
def kth_root(n, k):
    lo, hi = 1, max(1, int(n ** (1 / k)) + 2)   # 上界略松, 再用二分校正
    while lo <= hi:
        mid = (lo + hi) // 2
        p = mid ** k
        if p == n:
            return mid
        elif p < n:
            lo = mid + 1
        else:
            hi = mid - 1
    return None

def is_kth_power(n, k):
    return kth_root(n, k) is not None

print(is_kth_power(27, 3))    # True  3³
print(is_kth_power(16, 4))    # True  2⁴
print(is_kth_power(100, 2))   # True  10²
print(is_kth_power(999, 3))   # False
```

> **复杂度**：O(k·log n) 时间，O(1) 空间

> **知识点**：随机算法、在线流数据｜**难度**：⭐⭐（中等）｜**类型**：OI/采样

**思路**

💡 类比"火车票抽签发完前，谁都有机会被'顶替'"：从长度未知的流中均匀等概率抽取 k 个样本。前 k 个先进池，第 i（i>k）个以 `k/i` 概率随机替换池中某元素，即可保证每个元素被选中的概率均为 `k/N`。

```python
import random

def reservoir_sample(stream, k):
    pool = list(stream[:k])
    for i, x in enumerate(stream[k:], start=k + 1):
        j = random.randrange(i)      # 0..i-1
        if j < k:
            pool[j] = x
    return pool

random.seed(7)
print(sorted(reservoir_sample(range(1, 11), 3)))  # 从1..10均匀等概率抽3个
```

> **复杂度**：O(N) 时间，O(k) 空间

#### 12.26.2 例 98：不等权随机采样（前缀和 + 二分，OI）⭐⭐⭐

> **知识点**：前缀和、二分、加权抽样｜**难度**：⭐⭐⭐（困难）｜**类型**：OI/采样

**思路**

💡 类比"把饼按权重切成若干段，再在整根绳上随机落刀"：按权重构建前缀和数组，随机一个总长内的数，用二分找它落在哪个权重区间。这样每个下标被抽中的概率与其权重成正比。

```python
import random
import bisect

class WeightedPicker:
    def __init__(self, weights):
        self.pref = []
        s = 0
        for w in weights:
            s += w
            self.pref.append(s)
        self.total = s

    def pick(self):
        r = random.uniform(0, self.total)
        return bisect.bisect_left(self.pref, r)

random.seed(3)
wp = WeightedPicker([1, 3, 1])     # 权重和=5
n = 20000
cnt = [0, 0, 0]
for _ in range(n):
    cnt[wp.pick()] += 1
print([c / n for c in cnt])   # 约 [0.2, 0.6, 0.2]
```

> **复杂度**：O(n) 构建，O(log n) 采样

#### 12.27.2 例 100：海伦公式·三边求面积（OI）⭐⭐

> **知识点**：海伦公式、三角形合法性｜**难度**：⭐⭐（中等）｜**类型**：OI/面积变体

**思路**

💡 类比"不知道高，就靠'半周长'托底"：海伦公式 `S = √(p(p-a)(p-b)(p-c))`，其中 `p=(a+b+c)/2`。先用三角形不等式（两边和大于第三边）校验合法性，避免开方负数或零面积。

```python
import math

def heron_area(a, b, c):
    if a + b <= c or a + c <= b or b + c <= a:
        return 0.0            # 不构成三角形
    p = (a + b + c) / 2
    return math.sqrt(p * (p - a) * (p - b) * (p - c))

print(round(heron_area(3, 4, 5), 3))    # 6.0   3-4-5 三角形
print(round(heron_area(5, 5, 6), 3))    # 12.0  等腰
print(heron_area(1, 2, 5))              # 0.0   不能构成三角形
```

### 12.28 欧几里得进阶与日期

> 涵盖：最简分数、扩展欧几里得·丢番图方程、闰年天数统计。

#### 12.28.1 例 101：欧几里得·最简分数化简与比较（OI）⭐

> **知识点**：GCD 应用、比例化简｜**难度**：⭐（简单）｜**类型**：OI/数论应用

**思路**

💡 类比"把两个数都约到最简单比例"：分数化最简 = 分子分母同除它们的 gcd。也可用于将比例数字对化约，或通分后比较两个分数大小而避免浮点误差。

```python
from math import gcd

def reduce_frac(n, d):
    g = gcd(n, d)
    return n // g, d // g

def compare_frac(a_n, a_d, b_n, b_d):
    """返回 -1/0/1: a<b / a==b / a>b"""
    left, right = a_n * b_d, b_n * a_d
    return (left > right) - (left < right)

def ratio_reduce(nums):
    g = 0
    for v in nums:
        g = gcd(g, v)
    return [v // g for v in nums]

print(reduce_frac(12, 18))            # (2, 3)
print(compare_frac(1, 3, 2, 6))       # 0   相等
print(compare_frac(2, 3, 3, 4))       # -1  2/3 < 3/4
print(ratio_reduce([8, 12, 20]))      # [2, 3, 5]
```

> **复杂度**：O(log V) 时间，O(1) 空间

#### 12.28.2 例 102：扩展欧几里得·线性丢番图方程（OI）⭐⭐⭐

> **知识点**：扩展欧几里得、求解 ax+by=gcd｜**难度**：⭐⭐⭐（困难）｜**类型**：OI/模运算 bc

**思路**

💡 类比"倒着回溯每一次带余除法，把余数拼回系数"：扩展欧几里得不仅能算 gcd，还能给出整数解 `(x, y)` 使 `a·x + b·y = gcd(a,b)`。由此可求模逆元、解同余方程 `ax ≡ c (mod m)`。

```python
def exgcd(a, b):
    """返回 (g, x, y) 使 a*x + b*y = g = gcd(a,b)"""
    if b == 0:
        return a, 1, 0
    g, x1, y1 = exgcd(b, a % b)
    return g, y1, x1 - (a // b) * y1

def mod_inverse(a, m):
    g, x, _ = exgcd(a, m)
    if g != 1:
        return None            # 不存在逆元
    return x % m

print(exgcd(30, 18))           # (6, -1, 2)  30*(-1)+18*2=6
print(mod_inverse(3, 11))      # 4   3*4=12 ≡ 1 (mod 11)
print(mod_inverse(4, 6))       # None  gcd=2
```

> **复杂度**：O(log min(a,b)) 时间，O(log) 递归空间

#### 12.28.3 例 103：闰年判断与日期天数累加（OI）⭐⭐

> **知识点**：条件判断、日期累加｜**难度**：⭐⭐（中等）｜**类型**：OI/日期·标准求值变体

**思路**

💡 类比"每 4 年多的一天像'日历里的补丁'，但整百年要再花 400 才能补"：闰年 = 能被 4 整除且（不能被 100 整除或能被 400 整除）。据此累加某年 1 月 1 日到目标日期的天数，配合每月天数表，可用于"某日星期几"等求值变体。

```python
def is_leap(y):
    return y % 400 == 0 or (y % 4 == 0 and y % 100 != 0)

DAYS = [0, 31, 28, 31, 30, 31, 30, 31, 31, 30, 31, 30, 31]

def days_to(y, m, d):
    total = 0
    for yy in range(1, y):
        total += 366 if is_leap(yy) else 365
    mon_days = DAYS[:]
    if is_leap(y):
        mon_days[2] = 29
    total += sum(mon_days[:m]) + d
    return total

def weekday(y, m, d):
    # 2026-01-01 是星期四 => 使用基准
    base = days_to(2026, 1, 1)
    names = ['四', '五', '六', '日', '一', '二', '三']
    off = (days_to(y, m, d) - base) % 7
    return names[off]

print(is_leap(2024))          # True
print(is_leap(1900))          # False
print(is_leap(2000))          # True
print(days_to(2025, 12, 31))  # 2025 年最后一天累计天数
print(weekday(2026, 1, 1))    # '四'
print(weekday(2026, 8, 18))   # '二'
```

> **复杂度**：O(y) 时间，O(1) 空间

#### 12.29.1 例 104：汉明距离（LeetCode 461）⭐

> **知识点**：位运算、异或、数位统计｜**难度**：⭐（简单）｜**类型**：笔试面试/LeetCode

**思路**

💡 类比"数两边数码有几位对不上"：两个数二进制中对应位不同，其个数正好等于它们**异或**结果里 1 的个数。先 `x ^ y`，再用 `n & (n-1)` 逐次消掉最低位的 1 来数。

```python
def hammingDistance(x: int, y: int) -> int:
    z = x ^ y
    cnt = 0
    while z:
        z &= z - 1      # 每次消掉最低位的 1
        cnt += 1
    return cnt

print(hammingDistance(1, 4))   # 2  (001 vs 100)
print(hammingDistance(3, 1))   # 1
```

> **复杂度**：O(位数) 时间，O(1) 空间

#### 12.29.5 例 108：完美数（LeetCode 507）⭐

> **知识点**：约数求和、整数平方｜**难度**：⭐（简单）｜**类型**：笔试面试/LeetCode

**思路**

💡 类比"除了自己，把约数全加起来刚好还原回自己"：完美数指等于其**真因子（不含自身）之和**的正整数，如 6=1+2+3。只需枚举到 √n，因子成对 `(d, n//d)` 累加（剔除自身），最后与 n 比对。

```python
def checkPerfectNumber(num: int) -> bool:
    if num <= 1:
        return False
    s = 1
    d = 2
    while d * d <= num:
        if num % d == 0:
            s += d
            if d != num // d:
                s += num // d
        d += 1
    return s == num

print(checkPerfectNumber(28), checkPerfectNumber(6), checkPerfectNumber(7))   # True True False
```

> **复杂度**：O(√n) 时间，O(1) 空间

#### 12.30.2 例 111：曼哈顿与切比雪夫距离（OI）⭐

> **知识点**：L1/L∞ 距离、坐标旋转变换｜**难度**：⭐（简单）｜**类型**：OI/几何

**思路**

💡 类比"各种距离度量就像不同的走路规则"：曼哈顿距离 `|dx|+|dy|`，切比雪夫距离 `max(|dx|,|dy|)`。通过旋转变换 `(u,v)=(x+y, x-y)` 两者可互相转化，处理最值题时常用此技巧。

```python
def manhattan(p, q):
    return abs(p[0] - q[0]) + abs(p[1] - q[1])

def chebyshev(p, q):
    return max(abs(p[0] - q[0]), abs(p[1] - q[1]))

def manhattan_in_chebyshev(p, q):
    up = (p[0] + p[1], p[0] - p[1])
    vq = (q[0] + q[1], q[0] - q[1])
    return max(abs(up[0] - vq[0]), abs(up[1] - vq[1])) // 2

print(manhattan((0, 0), (3, 4)))              # 7
print(chebyshev((0, 0), (3, 4)))              # 4
print(manhattan_in_chebyshev((0, 0), (3, 4))) # 7（旋转后换度量）
```

> **复杂度**：O(1) 时间，O(1) 空间

### 12.31 进制与字符串数学

#### 12.31.1 例 113：字符串相加（LeetCode 415）⭐

**思路**

💡 类比"小学竖式，从个位往加且记住进位"：两个数字以字符串给出，从低位向高位逐位相加，维护进位 `carry`，最后结果逆序拼接，支持任意长度的"大数加法"。

```python
def addStrings(num1: str, num2: str) -> str:
    i, j = len(num1) - 1, len(num2) - 1
    carry = 0
    res = []
    while i >= 0 or j >= 0 or carry:
        d = carry
        if i >= 0:
            d += ord(num1[i]) - 48
            i -= 1
        if j >= 0:
            d += ord(num2[j]) - 48
            j -= 1
        res.append(str(d % 10))
        carry = d // 10
    return ''.join(reversed(res))
```

#### 12.31.2 例 114：x 的平方根·二分（LeetCode 69）⭐

**思路**

💡 类比"在 0..x 里用二分锁定满足 k²≤x 的最大整数"：整数平方根可用**二分**求 floor(√x)，避免浮点精度。对每个中点判断 `mid²` 与 x 的大小，不断收窄区间即可。

```python
def mySqrt(x: int) -> int:
    lo, hi = 0, x
    while lo <= hi:
        mid = (lo + hi) // 2
        if mid * mid <= x < (mid + 1) * (mid + 1):
            return mid
        if mid * mid > x:
            hi = mid - 1
        else:
            lo = mid + 1
    return -1

print(mySqrt(8), mySqrt(9), mySqrt(0))   # 2 3 0
```

### 12.32 质数与素性测试

> 涵盖：哥德巴赫猜想拆分、Miller-Rabin 概率素性测试。

#### 12.32.1 例 115：哥德巴赫猜想·双质数拆分（OI）⭐

> **知识点**：质数判定、枚举配对｜**难度**：⭐（简单）｜**类型**：OI/数论

**思路**

💡 类比"把一个大偶数摊成两块尽量接近的'雪花'（质数）"：哥德巴赫猜想断言每个 ≥4 的偶数都可拆成两个质数之和。对偶数 n 从小到大试 p，看 `n-p` 是否也是质数，找到即可。

```python
def is_prime(x):
    if x < 2:
        return False
    i = 2
    while i * i <= x:
        if x % i == 0:
            return False
        i += 1
    return True

def goldbach(n):
    for p in range(2, n // 2 + 1):
        if is_prime(p) and is_prime(n - p):
            return (p, n - p)
    return None

print(goldbach(10))                          # (3, 7)
print(sum(goldbach(1000)) == 1000)           # True 自校验
```

> **复杂度**：O(n·√n) 时间，O(1) 空间（可用质数筛优化到 O(n loglog n)）

#### 12.32.2 例 116：Miller-Rabin 素性检测（OI）⭐⭐

> **知识点**：费马小定理、二次探测、概率算法｜**难度**：⭐⭐（中等）｜**类型**：OI/数论进阶

**思路**

💡 类比"用几条'线索'交叉验证是不是质数"：把 n-1 写成 `d·2^s`，对随机基底 a，若 `a^d ≡ 1` 或连续平方中出现 -1（二次探测）则通过一轮；多轮均通过即几乎可断定是质数。比朴素试除快得多，适合大数素性判断。

```python
import random

def _mr_test(a, d, n, s):
    x = pow(a, d, n)
    if x == 1 or x == n - 1:
        return True
    for _ in range(s - 1):
        x = x * x % n
        if x == n - 1:
            return True
    return False

def is_prime_mr(n, rounds=8):
    if n < 2:
        return False
    if n in (2, 3):
        return True
    if n % 2 == 0:
        return False
    d, s = n - 1, 0
    while d % 2 == 0:
        d //= 2
        s += 1
    for _ in range(rounds):
        a = random.randrange(2, n - 2)
        if not _mr_test(a, d, n, s):
            return False
    return True

print(is_prime_mr(97), is_prime_mr(1000003))   # True True
print(is_prime_mr(561), is_prime_mr(100))      # False False（561 是卡迈克尔数）
```

> **复杂度**：O(k·log³ n) 时间（k 为轮数），O(1) 空间

### 12.33 同余·整除·计数

> 涵盖：线性同余方程通解、容斥原理求被整除计数。

#### 12.33.1 例 117：线性同余方程 ax ≡ b (mod m) 通解（OI）⭐⭐

> **知识点**：扩展欧几里得、同余方程、通解结构｜**难度**：⭐⭐（中等）｜**类型**：OI/数论

**思路**

💡 类比"在模世界里解一元一次方程，解的个数看 gcd"：方程 `ax ≡ b (mod m)` 有解当且仅当 `g = gcd(a, m)` 整除 b。用 ExGCD 求出一组特解 `x0`，再用约分后通解 `x ≡ x0 + k·(m/g)`（k 取 0..g-1）枚举出全部互不同余的解。

```python
def exgcd(a, b):
    if b == 0:
        return a, 1, 0
    g, x, y = exgcd(b, a % b)
    return g, y, x - (a // b) * y

def solve_congruence(a, b, m):
    g, x0, _ = exgcd(a, m)
    if b % g != 0:
        return []                     # 无解
    a, b, m = a // g, b // g, m // g
    x0 = x0 * b % m                   # 特解，m 已约分
    return [x0 + i * m for i in range(g)]   # 共 g 个互不同余的解

print(solve_congruence(6, 12, 18))   # [2, 5, 8, 11, 14, 17]
print(solve_congruence(2, 1, 4))     # []  无解
```

> **复杂度**：O(log m) 时间（ExGCD），O(g) 空间（输出解）

#### 12.34.1 例 119：整数拆分（LeetCode 343）⭐⭐

**思路**

💡 类比"把整数撕成若干加数，想让乘积最大"：`dp[i]` 为把 i 拆成至少两个正整数之和能得到的最大乘积，转移 `dp[i] = max(j*(i-j), j*dp[i-j])`。数论上最优是尽量拆成 3。

```python
def integerBreak(n: int) -> int:
    if n <= 3:
        return n - 1
    dp = [0] * (n + 1)
    dp[1] = 1
    for i in range(2, n + 1):
        for j in range(1, i):
            dp[i] = max(dp[i], j * (i - j), j * dp[i - j])
    return dp[n]

print(integerBreak(2), integerBreak(10))    # 1  36
```

#### 12.34.2 例 120：生日问题·碰撞概率（OI）⭐⭐

> **知识点**：概率乘积公式、随机模拟｜**难度**：⭐⭐（中等）｜**类型**：OI/概率

**思路**

💡 类比"教室里人数只要约 23 人，两人同生日概率就过半"：n 人生日各不相同的概率为 Π(365-i)/365，因此至少一对相同 = 1 - 上述乘积。用公式精确计算，并用大量随机模拟互相验证。

```python
import random

def birthday_theory(n):
    p = 1.0
    for i in range(n):
        p *= (365 - i) / 365
    return 1 - p

def birthday_sim(n, trials=20000):
    hit = 0
    for _ in range(trials):
        days = [random.randrange(365) for _ in range(n)]
        if len(set(days)) < n:
            hit += 1
    return hit / trials

print(round(birthday_theory(23), 3))   # 约 0.507
print(round(birthday_theory(50), 3))   # 约 0.970
print(round(birthday_sim(23), 2))      # 约 0.5
```

> **复杂度**：O(n) 时间（理论），O(n) 空间（模拟）

#### 12.34.4 例 122：无连续 1 的二进制串计数（OI）⭐

```python
def count_no_consecutive_ones(n):

    if n == 1:
        return 2
    a, b = 2, 3          # f[1], f[2]
    for _ in range(3, n + 1):
        a, b = b, a + b
    return b

print(count_no_consecutive_ones(1))    # 2
print(count_no_consecutive_ones(3))    # 5
```

#### 12.35.2 例 124：取石子博弈·区间 DP（OI）⭐⭐⭐

> **知识点**：区间动态规划、极大极小、差分状态｜**难度**：⭐⭐⭐（困难）｜**类型**：OI/博弈进阶

**思路**

💡 类比"双方轮流从两端取，我用'净差'来压缩博弈"：设 `dp[i][j]` 为当前局面为区间 [i..j]、轮到自己时"我方得分 − 对方得分"的最大值。取左端进入 `dp[i+1][j]` 且差值符号翻转，故 `dp[i][j] = max(piles[i]-dp[i+1][j], piles[j]-dp[i][j-1])`。

```python
def stone_game(piles):
    n = len(piles)
    dp = [[0] * n for _ in range(n)]
    for i in range(n):
        dp[i][i] = piles[i]
    for length in range(2, n + 1):
        for i in range(n - length + 1):
            j = i + length - 1
            dp[i][j] = max(piles[i] - dp[i + 1][j],
                           piles[j] - dp[i][j - 1])
    return dp[0][n - 1]

print(stone_game([5, 3, 4, 5]))    # 3 （净差>0 -> 先手必胜）
print(stone_game([8, 15, 3, 7]))   # >0
```

> **复杂度**：O(n²) 时间，O(n²) 空间

**思路**

💡 类比"按'当前位'分三种情况逐位统计 1"：对第 i 位把数字分成 high、cur、low 三段。若 `cur==0` 贡献 `high*i`；`cur==1` 贡献 `high*i + low+1`；`cur>1` 贡献 `(high+1)*i`。逐位累加得 1..n 中数字 1 总个数。

```python
def countDigitOne(n: int) -> int:
    cnt, i = 0, 1
    while i <= n:
        high = n // (i * 10)
        cur = (n // i) % 10
        low = n % i
        if cur == 0:
            cnt += high * i
        elif cur == 1:
            cnt += high * i + low + 1
        else:
            cnt += (high + 1) * i
        i *= 10
    return cnt

print(countDigitOne(0))     # 0
```

#### 12.36.2 例 126：第 N 个神奇数字（LeetCode 878）⭐⭐⭐

> **知识点**：最小公倍数、二分答案、容斥计数｜**难度**：⭐⭐⭐（困难）｜**类型**：LeetCode/数论

**思路**

💡 类比"在数轴上二分找一个位置，使其'神奇数'计数恰好到 N"：神奇数指能被 a 或 b 整除的数。mid 以内神奇数个数 = `mid//a + mid//b - mid//lcm(a,b)`（容斥）。对计数函数做**二分答案**找最小 x 使计数 ≥ N，答案对 1e9+7 取模。

```python
from math import gcd

def nthMagicalNumber(n: int, a: int, b: int) -> int:
    MOD = 10 ** 9 + 7
    l = a // gcd(a, b) * b
    def cnt(x):
        return x // a + x // b - x // l
    lo, hi = 2, min(a, b) * n
    while lo < hi:
        mid = (lo + hi) // 2
        if cnt(mid) < n:
            lo = mid + 1
        else:
            hi = mid
    return lo % MOD

print(nthMagicalNumber(1, 2, 3))   # 2
print(nthMagicalNumber(4, 2, 3))   # 6
print(nthMagicalNumber(5, 2, 4))   # 10
```

> **复杂度**：O(log(min(a,b)·n)) 时间，O(1) 空间

#### 12.36.3 例 127：最大公因数排序（LeetCode 1998）⭐⭐⭐

> **知识点**：质因数分解、并查集、连通性｜**难度**：⭐⭐⭐（困难）｜**类型**：LeetCode/数论

**思路**

💡 类比"把共享同一质因子的数用'绳子'绑成一组"：两数只要有一个公共质因子就能互相连通。对每个数做质因数分解，把"该数"与"该质因子可见的代表下标"用并查集合并；最后检查所有数是否属于同一连通块。

```python
class UF:
    def __init__(self, n):
        self.p = list(range(n))
        self.sz = [1] * n
    def find(self, x):
        while self.p[x] != x:
            self.p[x] = self.p[self.p[x]]
            x = self.p[x]
        return x
    def union(self, a, b):
        ra, rb = self.find(a), self.find(b)
        if ra == rb:
            return
        if self.sz[ra] < self.sz[rb]:
            ra, rb = rb, ra
        self.p[rb] = ra
        self.sz[ra] += self.sz[rb]

def canTraverseAllPairs(nums) -> bool:
    n = len(nums)
    if n == 1:
        return True
    uf = UF(n)
    def primes(x):
        d = 2
        while d * d <= x:
            if x % d == 0:
                yield d
                while x % d == 0:
                    x //= d
            d += 1 if d == 2 else 2
        if x > 1:
            yield x
    first = {}
    for i, v in enumerate(nums):
        for p in primes(v):
            if p in first:
                uf.union(i, first[p])
            else:
                first[p] = i
    root = uf.find(0)
    return all(uf.find(i) == root for i in range(n))

print(canTraverseAllPairs([2, 3, 6]))    # True
print(canTraverseAllPairs([3, 9, 5]))    # False
```

> **复杂度**：O(∑√v) 时间，O(n) 空间

#### 12.37.2 例 130：满足条件的子序列数目（LeetCode 1498）⭐⭐

> **知识点**：排序、双指针、组合幂、模运算｜**难度**：⭐⭐（中等）｜**类型**：笔试面试/LeetCode

**思路**

💡 类比"排序后固定左端，右指针把合格范围撑到最大"：子序列只关心元素集合，故排序。对左端 l 找到最大的 r 使 `nums[l]+nums[r]≤target`，则以 l 为最小值、右端可在 (l..r] 任选的子序列数为 `2^(r-l)`，累加取模。

```python
def numSubseq(nums, target: int) -> int:
    MOD = 10 ** 9 + 7
    nums.sort()
    n = len(nums)
    p = [1] * (n + 1)
    for i in range(1, n + 1):
        p[i] = p[i - 1] * 2 % MOD
    ans = 0
    l, r = 0, n - 1
    while l <= r:
        if nums[l] + nums[r] <= target:
            ans = (ans + p[r - l]) % MOD
            l += 1
        else:
            r -= 1
    return ans

print(numSubseq([3, 5, 6, 7], 9))    # 4
print(numSubseq([3, 3, 6, 8], 10))   # 6
```

#### 12.37.3 例 131：有效三角形的个数（LeetCode 611）⭐⭐

```python
def triangleNumber(nums) -> int:

    n = len(nums)
    cnt = 0
    for i in range(n):
        k = i + 2
        for j in range(i + 1, n):
            while k < n and nums[i] + nums[j] > nums[k]:
                k += 1
            cnt += max(0, k - j - 1)
    return cnt

print(triangleNumber([2, 2, 3, 4]))   # 3
print(triangleNumber([4, 2, 3, 4]))   # 4
```

### 12.38 丑数系列

#### 12.38.1 例 133：丑数 II（LeetCode 264）⭐⭐

> **知识点**：多路归并、三指针｜**难度**：⭐⭐（中等）｜**类型**：笔试面试/LeetCode

**思路**

💡 类比"三个水龙头分别 ×2、×3、×5，谁最小谁先出水"：用三个指针 i2/i3/i5 指向已生成丑数，每次取 `min(ugly[i2]*2, ugly[i3]*3, ugly[i5]*5)`，并让产生该值的指针前移；相同值需同时跳过多个指针，防止重复。

```python
def nthUglyNumber(n: int) -> int:

    i2 = i3 = i5 = 0
    while len(ugly) < n:
        nxt = min(ugly[i2] * 2, ugly[i3] * 3, ugly[i5] * 5)
        ugly.append(nxt)
        if nxt == ugly[i2] * 2:
            i2 += 1
        if nxt == ugly[i3] * 3:
            i3 += 1
        if nxt == ugly[i5] * 5:
            i5 += 1
    return ugly[-1]

print(nthUglyNumber(10))    # 12   (1,2,3,4,5,6,8,9,10,12)
print(nthUglyNumber(1))     # 1
```

> **复杂度**：O(n) 时间，O(n) 空间
