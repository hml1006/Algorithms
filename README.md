# 算法学习教程 (Algorithm Learning Tutorial)

> 从零开始，系统掌握数据结构与算法。覆盖 LeetCode 面试、信息学竞赛（OI/NOIP/ACM-ICPC）与人工智能算法体系。

本仓库是 [mdBook](https://rust-lang.github.io/mdBook/) 书籍源码。完整的前言、学习建议与复杂度速查表请阅读 [书籍前言](src/README.md)。

---

## 快速开始

```bash
# 安装 mdbook（如未安装）
cargo install mdbook

# 本地预览：http://localhost:3000
mdbook serve

# 构建静态站点到 book/
mdbook build
```

项目结构：

```text
.
├── book.toml          # mdBook 配置
├── src/               # 书籍正文
│   ├── SUMMARY.md     # 目录
│   ├── images/        # SVG / GIF 插图
│   └── *.md
└── book/              # 构建产物（已忽略）
```

## 三条学习路线

- **面试 / LeetCode**：0B → 01 → 02 → 03 → 04（树、Trie、并查集）→ 05（BFS/DFS、最短路）→ 06（背包、LIS/LCS）→ 07（KMP）→ 10（高频模式）。
- **OI / ACM 竞赛**：0A → 0B → 01 → 02 → 03 → 04 → 05 → 06 → 07 → 08 → 09 → 12a/12b/12c → 题库 12f–12s。
- **AI 算法**：0A（线代、概率）→ 0B → 01 → 06（基础 DP）→ 14 → 14a → 14b → 14c → 14d。

更细的阶段划分见 [12d 推荐学习路径](src/12d_推荐学习路径.md) 与 [14e AI 学习路径与资源](src/14e_学习路径与资源.md)。完整的分阶段自测标准与章节依赖见 [学习路线](src/学习路线.md)。
